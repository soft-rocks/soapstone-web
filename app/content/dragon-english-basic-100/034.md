# People wish they could live forever and never become older. However, if this wish came true, there would be too many people on the earth.

## 1. wish + could（`wish` S `could`）

句型公式：

**主詞 + `wish` + 主詞 + `could` + 動詞原形**

`wish` 後面的子句講現在做不到的事。子句裡用 `could` 加動詞原形。原句裡人們想永遠活著，但這件事做不到。

* I wish I could fly.
  我真希望我會飛。
* My brother wishes he could play the guitar.
  我弟弟真希望自己會彈吉他。

## 2. 假設句裡的 there would be（`there would be`）

句型公式：

**`If` + 主詞 + 過去式, + `there would be` + 名詞**

`if` 子句用過去式，講現在或未來的情況。說話的人把這個情況當成假設來說。這個情況可以是有可能發生的事，像 `if everyone came`。主要子句可以用 `there would be`，表示那時候會有某樣東西。

* If there were no trains, there would be more cars on the road.
  如果沒有火車，路上就會有更多車。
* If everyone came, there would be no seats left.
  如果每個人都來，就不會有空位了。

## 3. too many + 複數名詞（`too many` / `too much`）

句型公式：

**`too many` + 可數名詞複數**

**`too much` + 不可數名詞**

`too many` 和 `too much` 表示數量超過需要，造成問題。`too many` 接可數名詞，`too much` 接不可數名詞。

* There are too many people on this train.
  這班火車上人太多了。
* I drank too much coffee today.
  我今天喝了太多咖啡。
