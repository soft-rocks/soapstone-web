# Japanese people usually express their feelings as indirectly as possible so that they won’t offend others.

## 1. as + 形容詞 / 副詞 + as possible（`as` ... `as possible`）

句型公式：

**`as` + 形容詞 / 副詞 + `as possible`**

**`as` + 形容詞 / 副詞 + `as` + 主詞 + `can` / `could`**

這個句型的意思是盡可能做到某個程度。`as possible` 可以換成 `as` 加主詞加 `can`。主要子句是過去式的時候用 `could`。

* Please come home as soon as possible.
  請盡快回家。
* I ran as fast as I could.
  我用最快的速度跑。
* Keep your answers as short as possible.
  你的回答盡量簡短。

## 2. so that 表示目的（`so that` clause of purpose）

句型公式：

**主要子句 + `so that` + 主詞 + `can` / `won't` + 動詞原形**

**主要子句 + `so that` + 主詞 + `could` / `wouldn't` + 動詞原形**

`so that` 帶出的子句表示目的。子句裡常用 `can` 或否定的 `won't`。主要子句是過去式的時候，改用 `could` 或 `wouldn't`。

* I'll write it down so that I won't forget.
  我會把它寫下來，這樣我就不會忘記。
* She spoke slowly so that everyone could understand.
  她講得很慢，讓每個人都聽得懂。

## 3. 例句

1. Japanese people usually express their feelings as indirectly as possible so that they won’t offend others.
日本人通常會盡量委婉地表達自己的感受，以免冒犯別人。
2. Please come home as soon as possible.
請盡快回家。
3. I ran as fast as I could.
我用最快的速度跑。
4. Please speak as clearly as possible.
請盡可能講清楚。
5. Keep your answers as short as possible.
你的回答盡量簡短。
6. I'll finish the report as quickly as I can.
我會盡快把報告做完。
7. She answered the questions as politely as she could.
她盡可能有禮貌地回答問題。
8. We left home as early as possible to avoid the traffic.
我們盡早離開家，避開塞車。
9. Keep the room as quiet as possible. The baby is sleeping.
讓房間盡可能保持安靜。寶寶在睡覺。
10. I'll write it down so that I won't forget.
我會把它寫下來，這樣我就不會忘記。
11. She spoke slowly so that everyone could understand.
她講得很慢，讓每個人都聽得懂。
12. I'll set my alarm so that I won't be late.
我會設鬧鐘，這樣我才不會遲到。
13. Talk quietly so that you won't wake the baby.
小聲講話，這樣才不會吵醒寶寶。
14. I study English every day so that I can talk with people from other countries.
我每天讀英文，這樣我才能跟其他國家的人聊天。
15. Let's leave now so that we can catch the last train.
我們現在出發吧，這樣才趕得上末班車。
16. My father works hard so that we can live a good life.
我爸爸努力工作，讓我們能過好日子。
17. He took a taxi so that he could arrive on time.
他搭了計程車，這樣他才能準時到。
18. I wore a coat so that I wouldn't catch a cold.
我穿了外套，這樣才不會感冒。
19. We whispered so that the teacher wouldn't hear us.
我們小聲講話，這樣老師才不會聽到我們。
20. She went to bed early so that she could get up at five.
她很早就去睡覺，這樣她才能五點起床。
21. I smiled as naturally as I could so that my mother wouldn't worry.
我盡可能自然地笑，這樣我媽媽才不會擔心。
22. Drive as carefully as possible so that you won't have an accident.
盡可能小心開車，這樣你才不會出車禍。
23. Many Taiwanese students study as hard as they can so that they can get into a good university.
很多台灣學生盡全力讀書，這樣他們才能進好大學。
24. We packed as little as possible so that we could walk around easily.
我們行李帶得越少越好，這樣才能輕鬆地到處走。
25. In Japan, people speak quietly on the train so that they won't bother others.
在日本，人們在火車上小聲講話，這樣才不會打擾到別人。
26. I wrote my name on my umbrella so that I could find it easily.
我在雨傘上寫了名字，這樣才好找。
27. Please reply as soon as you can.
請盡快回覆。
28. He explained the rules as simply as possible.
他盡可能簡單地說明規則。
29. Put the milk in the fridge so that it won't go bad.
把牛奶放進冰箱，這樣才不會壞掉。
30. I saved money every month so that I could visit my friend in Osaka.
我每個月存錢，這樣我才能去大阪看我朋友。
