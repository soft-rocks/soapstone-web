The teacher says that we should wait here for a while because if we left now, we might get caught in a thunderstorm on the way.

老師說我們應該在這裡等一下，因為如果現在離開，路上可能會遇到雷雨。

say that 轉⁠述別⁠人⁠的⁠話，子⁠句⁠的 should 表⁠示建⁠議

The teacher says that we should wait here for a while because if we left now, we might get caught in a thunderstorm on the way.

我媽媽說我應該早點睡。

原句的老師建議大家在這裡等。

主⁠要動⁠詞是現⁠在⁠式 says 時，子⁠句⁠的時⁠態不⁠用往⁠前推

The teacher says that we should wait here for a while because if we left now, we might get caught in a thunderstorm on the way.

if 子⁠句用過⁠去⁠式，講現⁠在或未⁠來⁠的情⁠況

The teacher says that we should wait here for a while because if we left now, we might get caught in a thunderstorm on the way.

說話的人把這個情況當成假設。這個情況有可能發生。

主⁠要⁠子⁠句用 would、could 或 might 加動⁠詞⁠原⁠形

The teacher says that we should wait here for a while because if we left now, we might get caught in a thunderstorm on the way.

would

If we left now, we would get home before dinner.

如果我們現在走，就會在晚餐前到家。
could

If I had more time, I could help you.

如果我有更多時間，我就可以幫你。
might

If we took the bus, we might be late.

如果我們搭公車，可能會遲到。

might 表示不確定。

get caught in 表⁠示遇⁠上不⁠好⁠的⁠事，沒⁠辦⁠法躲⁠開

The teacher says that we should wait here for a while because if we left now, we might get caught in a thunderstorm on the way.

我們回家路上遇上了雨。

get 加過去分詞表示被動。

get caught in 後⁠面常接 rain、storm、traffic

The teacher says that we should wait here for a while because if we left now, we might get caught in a thunderstorm on the way.

rain

Take an umbrella, or you'll get caught in the rain.

帶把傘，不然你會遇上雨。
storm

If we went out now, we might get caught in the storm.

如果我們現在出去，可能會遇上暴風雨。
traffic

I got caught in heavy traffic this morning.

我今天早上遇上了大塞車。
