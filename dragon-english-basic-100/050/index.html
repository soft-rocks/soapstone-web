I’m so busy doing the housework every day that I have no time to see a movie.

我每天忙著做家事，忙到沒有時間去看電影。

be busy 後⁠面直⁠接接動⁠名⁠詞，不⁠加 to

I’m so busy doing the housework every day that I have no time to see a movie.

be busy 加動名詞表示忙著做某件事。

be busy 後⁠面⁠接名⁠詞⁠時用 be busy with

I’m so busy doing the housework every day that I have no time to see a movie.

動名詞

My mother is busy cooking dinner.

我媽媽正忙著煮晚餐。
with + 名詞

I was busy with my homework last night.

我昨晚忙著寫作業。

so 表⁠示程⁠度很⁠高，that 子⁠句說⁠出這⁠個程⁠度帶⁠來⁠的結⁠果

I’m so busy doing the housework every day that I have no time to see a movie.

我每天忙著做家事，忙到沒有時間去看電影。

so ... that 的 that 在口⁠語⁠裡常省⁠略

I’m so busy doing the housework every day that I have no time to see a movie.

音樂大聲到我聽不到你說話。

to 不⁠定⁠詞放⁠在 time 後⁠面，說⁠明這⁠是做⁠什⁠麼事⁠的時⁠間

I’m so busy doing the housework every day that I have no time to see a movie.

我沒有時間去看電影。

have no time to 也⁠可⁠以寫⁠成 don't have time to

I’m so busy doing the housework every day that I have no time to see a movie.

have no time to

I have no time to eat breakfast.

我沒有時間吃早餐。
don't have time to

I don't have time to watch TV on weekdays.

我平日沒有時間看電視。
