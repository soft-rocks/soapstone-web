If you expect that schools only teach academic subjects, then this proves that you don’t understand what schools are for.

如果你以為學校只教學科，那就證明你不懂學校是做什麼用的。

if 子⁠句講條⁠件，then 帶⁠出後⁠面⁠的結⁠果

If you expect that schools only teach academic subjects, then this proves that you don’t understand what schools are for.

如果你以為學校只教學科，那就證明你不懂學校是做什麼用的。

疑⁠問⁠句放⁠進句⁠子⁠裡當受⁠詞⁠時，主⁠詞在⁠前，動⁠詞在⁠後

If you expect that schools only teach academic subjects, then this proves that you don’t understand what schools are for.

What are schools for? 放進句子裡變成 what schools are for。

介⁠系⁠詞 for 留⁠在子⁠句最⁠後，what ... for 問⁠的⁠是用⁠途

If you expect that schools only teach academic subjects, then this proves that you don’t understand what schools are for.

按鈕的用途

Do you know what this button is for?

你知道這個按鈕是做什麼用的嗎？
考試的目的

Students should understand what tests are for.

學生應該了解考試是做什麼用的。

prove that 表⁠示證⁠明某⁠件⁠事是真⁠的

If you expect that schools only teach academic subjects, then this proves that you don’t understand what schools are for.

主詞 this 指前面 if 子句講的想法。

expect that 表⁠示預⁠期某⁠件⁠事會發⁠生，或認⁠為某⁠件⁠事是這⁠樣

If you expect that schools only teach academic subjects, then this proves that you don’t understand what schools are for.

預期會發生

We expect that more tourists will come to Taiwan next year.

我們預期明年會有更多觀光客來台灣。
認為是這樣

If you expect that everything will be easy, then you will be disappointed.

如果你以為每件事都會很簡單，那你會失望的。
