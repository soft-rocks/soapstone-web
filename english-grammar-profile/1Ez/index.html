Is it possible to pay by credit card? If so, which ones do you take?

可以刷信用卡嗎？如果可以，你們收哪幾種卡？

if so 承⁠接是⁠非問⁠句

Is it possible to pay by credit card? If so, which ones do you take?

你星期六有空嗎？如果有空，我們去海邊吧。

意思是如果答案是肯定的。

so 代⁠替問⁠句⁠的內⁠容

Is it possible to pay by credit card? If so, which ones do you take?

完整的子句

If you are free on Saturday, let's go to the beach.

如果你星期六有空，我們去海邊吧。
省略

If so, let's go to the beach.

如果有空，我們去海邊吧。

前⁠面是直⁠接問⁠句或間⁠接⁠問⁠句

Is it possible to pay by credit card? If so, which ones do you take?

直接問句

Does the hotel have a pool? If so, don't forget your swimsuit.

飯店有游泳池嗎？如果有，別忘了帶泳衣。
間接問句
whether / if

Please tell me whether you need a lift. If so, I'll pick you up at six.

請告訴我你需不需要人載。如果需要，我六點去接你。

主⁠要⁠子⁠句是問⁠句

Is it possible to pay by credit card? If so, which ones do you take?

疑問句的語序

Have you been to Japan before? If so, which cities did you visit?

你以前去過日本嗎？如果去過，你去了哪些城市？

and, if so, 放⁠在句中

前後加逗號

The form asks whether you have ever lived abroad and, if so, for how long.

表格問你有沒有在國外住過，如果有，住了多久。

原句：先問可⁠不⁠可⁠以，再問哪幾⁠種

Is it possible to pay by credit card? If so, which ones do you take?

可以刷信用卡嗎？如果可以，你們收哪幾種卡？

If so 是 If it is possible to pay by credit card 的省略。ones 指信用卡。

if 後⁠面直⁠接接 so

Is it possible to pay by credit card? If so, which ones do you take?

Is it possible to pay by card? If it so, which cards do you accept?

Is it possible to pay by card? If so, which cards do you accept?

問⁠句⁠的助⁠動⁠詞放⁠在主⁠詞前⁠面

Is it possible to pay by credit card? If so, which ones do you take?

Do you sell stamps? If so, how much one costs?

Do you sell stamps? If so, how much does one cost?

if so 前⁠面要⁠是是⁠非問⁠句

Is it possible to pay by credit card? If so, which ones do you take?

Where do you live? If so, I'll visit you.

Do you live near here? If so, I'll visit you.

if not 接否⁠定⁠時要做⁠的事

if so
肯定

Is the café still open? If so, let's get a coffee.

咖啡店還開著嗎？如果開著，我們去喝杯咖啡。
if not
否定

Is the café still open? If not, let's go home.

咖啡店還開著嗎？如果沒開，我們就回家。

連⁠接⁠詞 so 說已⁠經確⁠定⁠的事

so
所以

My phone battery was low, so I borrowed my sister's charger.

我的手機快沒電了，所以我跟我妹借了充電器。
if so
條件

Is it raining? If so, we'll stay in.

在下雨嗎？如果在下雨，我們就待在家裡。

例句

① 直接問句 + If so

  1. Do you like Italian food? If so, you'll love this restaurant.
    你喜歡義大利菜嗎？如果喜歡，你一定會愛這家餐廳。
  2. Are you feeling tired? If so, go to bed early tonight.
    你覺得累嗎？如果累，今晚就早點睡。
  3. Is the printer working again? If so, I'll print the tickets now.
    印表機又可以用了嗎？如果可以，我現在就印票。
  4. Have you finished with the ladder? If so, I'll put it back in the garage.
    梯子你用完了嗎？如果用完了，我就把它放回車庫。
  5. Did the parcel arrive this morning? If so, please put it in my office.
    包裹今天早上到了嗎？如果到了，請放在我的辦公室。
  6. Is your brother still looking for a job? If so, he should call my uncle.
    你哥哥還在找工作嗎？如果是，他應該打電話給我叔叔。
  7. Was the film any good? If so, I might watch it this weekend.
    那部電影好看嗎？如果好看，我這個週末可能會去看。
  8. Is it your birthday today? If so, the dessert is free.
    今天是你的生日嗎？如果是，甜點免費。

② 間接問句 + If so

  1. I'm not sure whether the shop is open today. If so, I'll buy some bread.
    我不確定那家店今天有沒有開。如果有開，我會去買些麵包。
  2. Please let me know if you need a hotel room. If so, I'll book one for you.
    請告訴我你需不需要飯店房間。如果需要，我會幫你訂一間。
  3. I wonder whether Tom has heard the news. If so, he must be very upset.
    不知道 Tom 聽到消息了沒。如果聽到了，他一定很難過。
  4. Check whether the milk has gone off. If so, throw it away.
    看看牛奶是不是壞了。如果壞了，就丟掉。
  5. Find out if the train is delayed. If so, we'll take a taxi.
    查一下火車有沒有誤點。如果有，我們就搭計程車。
  6. The doctor will ask whether you're taking any medicine. If so, bring the boxes with you.
    醫生會問你有沒有在吃藥。如果有，把藥盒帶去。
  7. I'd like to know whether the job includes travel. If so, I'm very interested.
    我想知道這份工作需不需要出差。如果需要，我很有興趣。

③ If so + 問句

  1. Do you play any instruments? If so, which ones do you play?
    你會演奏樂器嗎？如果會，你會哪些？
  2. Are you coming to the meeting? If so, could you bring the report?
    你會來開會嗎？如果會，可以帶報告來嗎？
  3. Have you finished with the newspaper? If so, can I have it?
    報紙你看完了嗎？如果看完了，可以給我嗎？
  4. Is there a car park near the stadium? If so, how much does it cost?
    體育場附近有停車場嗎？如果有，要多少錢？
  5. Did anyone see the accident? If so, why didn't they call the police?
    有人看到那場意外嗎？如果有，為什麼沒人報警？
  6. Is the museum free on Sundays? If so, what time does it open?
    博物館星期天免費嗎？如果是，幾點開門？
  7. Do you have any brothers or sisters? If so, are they older than you?
    你有兄弟姊妹嗎？如果有，他們比你大嗎？

④ and, if so,

  1. Ask the guests whether they have any allergies and, if so, what they can't eat.
    問問客人有沒有過敏，如果有，有什麼不能吃。
  2. I'd like to know whether the flight is full and, if so, when the next one leaves.
    我想知道這班飛機是不是客滿了，如果是，下一班什麼時候起飛。
  3. The survey asks whether people own a car and, if so, how often they use it.
    這份調查問大家有沒有車，如果有，多久用一次。
  4. Please tell us whether you will attend and, if so, how many guests you'll bring.
    請告訴我們您是否會出席，如果會，會帶幾位客人來。
  5. The police want to know whether the man was armed and, if so, what kind of weapon he had.
    警方想知道那個男人有沒有帶武器，如果有，是哪一種武器。

⑤ 信件和公告

  1. Are you over sixty-five? If so, you can travel free on local buses.
    您年滿六十五歲了嗎？如果是，您可以免費搭乘本地公車。
  2. Have you changed your address recently? If so, please update your details online.
    您最近換了地址嗎？如果是，請上網更新您的資料。
  3. Do you suffer from lethargy in the afternoons? If so, try a short walk after lunch.
    您下午常常昏昏欲睡嗎？如果是，午餐後試著散步一下。
  4. Did you find our staff obliging? If so, please leave us a review.
    您覺得我們的員工親切熱心嗎？如果是，請給我們留個評論。
  5. Is your child's school closed tomorrow? If so, the library offers free activities for children.
    您孩子的學校明天停課嗎？如果是，圖書館有提供兒童免費活動。
