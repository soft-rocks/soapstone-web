Spring is the best time because there aren't too many tourists.

春天是最好的時節，因為觀光客沒那麼多。

複⁠數名⁠詞⁠的否⁠定用 there aren't

春天是最好的時節，因為觀光客沒那麼多。

be 照名⁠詞和時⁠態選

Spring is the best time because there aren't too many tourists.

單數名詞

There isn't a post office near my flat.

我家附近沒有郵局。
不可數名詞

There isn't any noise at night.

晚上一點聲音都沒有。
過去式，複數名詞

There weren't any buses after midnight.

半夜以後一班公車都沒有。

any 是一⁠個都⁠沒⁠有，many 和 much 是不⁠多

any
一個都沒有

There aren't any apples in the bowl.

碗裡一顆蘋果都沒有。
many
不多

There aren't many apples on the tree this year.

今年樹上的蘋果不多。
much
不多

There isn't much bread left.

麵包剩不多了。

複⁠數名⁠詞用 aren't

Spring is the best time because there aren't too many tourists.

There isn't any chairs in the room.

There aren't any chairs in the room.

否⁠定⁠句⁠的名⁠詞前⁠面用 any，不⁠用 some

Spring is the best time because there aren't too many tourists.

There aren't some shops near here.

There aren't any shops near here.

一⁠句⁠裡只⁠用一⁠個否⁠定

Spring is the best time because there aren't too many tourists.

There isn't no parking at the hospital.

There isn't any parking at the hospital.

There's no parking at the hospital. 也對。

說某⁠個地⁠方沒⁠有東⁠西，用 there isn't

Spring is the best time because there aren't too many tourists.

In my town don't have a cinema.

In my town there isn't a cinema.

no 加名⁠詞也⁠是否⁠定

Spring is the best time because there aren't too many tourists.

There's no hot water this morning.

今天早上沒有熱水。

說某⁠個東⁠西⁠的情⁠況，用 it isn't

Spring is the best time because there aren't too many tourists.

There's a café on the corner, but it isn't open today.

轉角有一家咖啡店，可是今天沒開。

例句

① There isn't a / an + 單數名詞

  1. "Can I take money out here?" "No, there isn't a bank in this village."
    我可以在這裡領錢嗎？不行，這個村子沒有銀行。
  2. There isn't a lift, so we have to carry the sofa up the stairs.
    沒有電梯，所以我們得把沙發抬上樓梯。
  3. Sorry, there isn't a table for four until eight o'clock.
    抱歉，八點以前沒有四人桌。
  4. There isn't a bus to the beach on Sundays.
    星期天沒有去海灘的公車。

② There aren't any + 複數名詞

  1. "Can I have an egg sandwich?" "Sorry, there aren't any eggs left."
    我可以點一個蛋三明治嗎？抱歉，蛋都賣完了。
  2. There aren't any chairs in the meeting room. Where did they go?
    會議室裡一張椅子都沒有。椅子都到哪裡去了？
  3. My village is boring. There aren't any shops or cafés.
    我的村子很無聊。一家商店或咖啡店都沒有。
  4. There aren't any clean cups. Can you wash some?
    沒有乾淨的杯子了。你可以洗幾個嗎？

③ There isn't any + 不可數名詞

  1. The flat is very quiet. There isn't any noise at night.
    這間公寓很安靜。晚上一點聲音都沒有。
  2. "Can I have a coffee with milk?" "Sorry, there isn't any milk."
    我可以要一杯加牛奶的咖啡嗎？抱歉，沒有牛奶了。
  3. There isn't any information about the trip on the website yet.
    網站上還沒有這趟旅行的任何資訊。
  4. We can't make a cake. There isn't any sugar.
    我們沒辦法做蛋糕。沒有糖。

④ There aren't many / There isn't much

  1. June is nice here because there aren't too many insects yet.
    這裡六月很舒服，因為蟲還不會太多。
  2. There aren't many people at the gym on Friday nights.
    星期五晚上健身房人不多。
  3. Let's go now. There isn't much time.
    我們現在走吧。時間不多了。
  4. "Is the city busy at night?" "Not really. There isn't much traffic after nine."
    這個城市晚上熱鬧嗎？還好。九點以後車子不多。
  5. There aren't many good jobs in my town, so young people move away.
    我住的小鎮好工作不多，所以年輕人都搬走了。

⑤ There wasn't + 單數名詞 / 不可數名詞

  1. I looked at the card, but there wasn't any message on it.
    我看了那張卡片，可是上面沒有寫任何話。
  2. There wasn't a cloud in the sky all day.
    一整天天上一朵雲都沒有。
  3. "Did you have a good holiday?" "Not really. There wasn't much sun."
    你假期過得好嗎？不太好。沒什麼太陽。
  4. There wasn't any hot water in the hotel, so I had a cold shower.
    飯店沒有熱水，所以我洗了冷水澡。

⑥ There weren't + 複數名詞

  1. It was late, and there weren't any people on the bus.
    那時很晚了，公車上一個人都沒有。
  2. When we arrived, there weren't any seats left.
    我們到的時候，已經沒有位子了。
  3. "Was the concert good?" "Yes, but there weren't many people there."
    演唱會好看嗎？好看，可是人不多。
  4. There weren't any taxis at the station, so we walked.
    車站一輛計程車都沒有，所以我們用走的。

⑦ 問句：Isn't there ...? / Aren't there ...?

  1. "Isn't there a supermarket near here?" "No, the nearest one is in town."
    這附近沒有超市嗎？沒有，最近的在市區。
  2. Aren't there any vegetarian dishes on the menu?
    菜單上沒有素食的菜嗎？
  3. "Wasn't there a park here before?" "Yes, but they built flats on it."
    這裡以前不是有一座公園嗎？對，可是他們在那裡蓋了公寓。

⑧ 寫信和留言

  1. Hi Tom, there isn't any food in the fridge, so let's eat out tonight.
    嗨 Tom，冰箱裡沒有食物了，我們今晚出去吃吧。
  2. Dear Sir, I booked a double room, but there wasn't a bath in the room.
    您好，我訂的是雙人房，可是房間裡沒有浴缸。
  3. Mum, there aren't any towels in the bathroom. Can you bring one?
    媽，浴室裡沒有毛巾。你可以拿一條來嗎？
