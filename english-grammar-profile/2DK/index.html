Should you require any further information, please do not hesitate to ask.

如果您需要任何進一步的資訊，請不要客氣，儘管發問。

should 放⁠到主⁠詞前⁠面，取⁠代 if

Should you require any further information, please do not hesitate to ask.

如果您看到任何可疑的東西，請報警。

這個句型說未來可能發生的事，用在正式的書面文字。

主⁠要⁠子⁠句用祈⁠使⁠句、will 或現⁠在⁠式

Should you require any further information, please do not hesitate to ask.

祈使句
要對方做的事

Should the lift break down, use the stairs.

如果電梯故障，請走樓梯。
will
會發生的事

Should it rain on Saturday, the concert will move to the town hall.

如果星期六下雨，音樂會會改到市政廳舉行。
現在式
固定的規定

Should you choose the premium plan, you get free delivery.

如果您選高級方案，就享有免運。

Should + there + be + 名⁠詞

there be

Should there be a delay, we will let you know.

如果有延誤，我們會通知您。
there be

Should there be a fire, the doors will open automatically.

如果發生火災，門會自動打開。

否⁠定和被⁠動

not + 原形動詞
否定

Should the medicine not help, see your doctor again.

如果這種藥沒有幫助，請再去看醫生。
be + 過去分詞
被動

Should your flight be delayed, the airline will pay for a hotel.

如果您的航班延誤，航空公司會出飯店的錢。

not 放在主詞後面。

原句：正⁠式信⁠件⁠的結⁠尾

Should you require any further information, please do not hesitate to ask.

如果您需要任何進一步的資訊，請不要客氣，儘管發問。

require 是 need 的正式說法。do not hesitate to ask 請對方儘管發問。

there 放⁠在 should 後⁠面，be 放⁠在 there 後⁠面

Should be there any delays, we will inform you.

Should there be any delays, we will inform you.

should 後⁠面⁠接原⁠形⁠動⁠詞

Should you require any further information, please do not hesitate to ask.

Should you needed more time, please ask.

Should you need more time, please ask.

倒⁠裝⁠的句⁠型要⁠有主⁠詞

Should you require any further information, please do not hesitate to ask.

Should need a ticket, ask the driver.

Should you need a ticket, ask the driver.

If + 主⁠詞 + should 意⁠思一⁠樣，也用在口⁠語

If you should

If you should need a lift home, just ask.

如果你需要人載你回家，儘管說。
If it should

If it should snow tonight, the school will close.

如果今晚下雪，學校會停課。

should 放⁠在主⁠詞後⁠面說建⁠議

主詞 + should
建議

You should check the timetable.

你應該查一下時刻表。
Should + 主詞
條件

Should you check the timetable, you will see the change.

如果你查一下時刻表，就會看到這個變動。

例句

① 主要子句用祈使句

  1. Should you need a taxi, ask at the front desk.
    如果您需要計程車，請到櫃台詢問。
  2. Should you lose your key card, contact reception immediately.
    如果您弄丟房卡，請馬上聯絡櫃台。
  3. Should anyone call while I'm out, take a message.
    如果我出去時有人打電話來，請幫我留言。
  4. Should you have any difficulty finding the office, please phone me.
    如果您找不到辦公室，請打電話給我。
  5. Should the alarm go off, leave the building by the nearest exit.
    如果警報響了，請從最近的出口離開大樓。
  6. Should you notice anything unusual, inform the security staff.
    如果您注意到任何異常，請通知保全人員。
  7. Should you wish to bring a guest, please let us know by Monday.
    如果您想帶客人來，請在星期一前告訴我們。

② 主要子句用 will 或現在式

  1. Should you book before May, you will get a ten percent discount.
    如果您五月前預訂，就能打九折。
  2. Should the train arrive late, the hotel will hold your room.
    如果火車晚到，飯店會幫您保留房間。
  3. Should it rain on Saturday, the concert will move to the town hall.
    如果星期六下雨，音樂會會改到市政廳舉行。
  4. Should you choose the premium plan, you get free delivery.
    如果您選高級方案，就享有免運。
  5. Should the price drop, I will buy two.
    如果價格下降，我會買兩個。
  6. Should the pain return, the patient takes another tablet.
    如果疼痛再出現，病人就再吃一顆藥。

③ Should there be

  1. Should there be any problems, please call our helpline.
    如果有任何問題，請打我們的服務專線。
  2. Should there be a fire, the doors will open automatically.
    如果發生火災，門會自動打開。
  3. Should there be any changes to the programme, we will post them on our website.
    如果節目有任何更動，我們會公布在網站上。
  4. Should there be a lack of trust between partners, the business will fail.
    如果合夥人之間缺乏信任，生意會失敗。
  5. Should there be any seats left, the box office will sell them at the door.
    如果還有剩下的位子，售票處會在門口賣。

④ 否定

  1. Should you not be satisfied with the product, return it within thirty days.
    如果您對產品不滿意，請在三十天內退回。
  2. Should the shop not have your size, the assistant will order it for you.
    如果店裡沒有您的尺寸，店員會幫您訂。
  3. Should the client not reply by Monday, send a reminder.
    如果客戶星期一前沒回覆，就寄一封提醒信。
  4. Should the bus not come, walk to the station.
    如果公車沒來，就走路去車站。

⑤ 被動

  1. Should your luggage be damaged, fill in this form.
    如果您的行李損壞，請填這張表格。（被動）
  2. Should the event be cancelled, the organizers will refund all tickets.
    如果活動取消，主辦單位會退還所有的票款。（被動）
  3. Should your card be stolen, call the bank at once.
    如果您的卡被偷，請馬上打電話給銀行。（被動）
  4. Should the package be returned, we will contact you.
    如果包裹被退回，我們會跟您聯絡。（被動）

⑥ 正式信件和公告

  1. Should you require further details, please consult our website.
    如果您需要更多細節，請查閱我們的網站。
  2. Should you glean any useful information, please share it with the team.
    如果您蒐集到任何有用的資訊，請跟團隊分享。
  3. Should any noise become obtrusive, please inform the manager.
    如果有任何噪音干擾到您，請告訴經理。
  4. Should you wish to advocate a different approach, raise it at the meeting.
    如果您想主張用不同的做法，請在會議上提出。
  5. Should a member of staff be absent, a colleague will cover the shift.
    如果有員工缺席，會由一位同事代班。
  6. Should you have any further questions, our staff will be happy to help.
    如果您還有任何問題，我們的員工很樂意幫忙。
