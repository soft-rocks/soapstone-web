It is likely that by reading books we will learn some new words.

透過讀書，我們很可能會學到一些新單字。

It + is / seems + likely / possible / probable + that + 子⁠句

likely / probable、possible、seem

likely / probable很可能。
possible有可能。
seem讓判斷再委婉一點。
that 子句說話者不想說得太肯定的那件事。

直⁠接和委⁠婉⁠的說⁠法

直接

Only one computer will do this.

只有一台電腦會做這件事。
委婉

It is possible that only one computer will do this.

有可能只有一台電腦會做這件事。

否⁠定⁠的委⁠婉說⁠法

例句

It does not seem possible that we can live without any private life.

我們似乎不可能完全沒有私生活。

It does not seem possible that 表示說話者覺得不太可能，但不說死。

表⁠示「很⁠可⁠能」的形⁠容⁠詞是 likely

It is likely that by reading books we will learn some new words.

It is like that we will win.

It is likely that we will win.

seem 的否⁠定用 does not seem

It not seems possible that he did it.

It does not seem possible that he did it.

is 後⁠面⁠接形⁠容⁠詞 possible，不⁠接副⁠詞

It is likely that by reading books we will learn some new words.

It is possibly that we will win.

It is possible that we will win.

例句

① It is likely / probable + that + 子句

  1. It is likely that regular exercise will improve your sleep.
    規律運動很可能會改善你的睡眠。
  2. It is likely that more people will work from home in the future.
    將來很可能會有更多人在家工作。
  3. It is probable that the price of food will continue to rise.
    食物的價格很可能會繼續上漲。
  4. It's likely that the new law will reduce pollution.
    新法律很可能會減少污染。
  5. It is likely that most students will choose the easier course.
    大部分的學生很可能會選比較簡單的課。
  6. It is probable that the meeting will run late.
    會議很可能會延後結束。
  7. It's likely that she has already heard the news.
    她很可能已經聽說了這個消息。
  8. It is likely that the team will need more money.
    這個團隊很可能需要更多錢。

② It is possible + that + 子句

  1. It is possible that the storm will reach the coast tonight.
    暴風雨今晚有可能會到達海岸。
  2. It is possible that the results are wrong.
    結果有可能是錯的。
  3. It's possible that he forgot about the appointment.
    他有可能忘了約會。
  4. It is possible that children learn more from games than from books.
    小孩從遊戲學到的有可能比從書上學到的多。
  5. It is possible that the train is delayed.
    火車有可能誤點了。（被動）
  6. It's possible that we'll have to change our plans.
    我們有可能得改變計畫。
  7. It is possible that the museum will close for a year.
    博物館有可能會關閉一年。
  8. It is possible that the company made a mistake.
    那家公司有可能犯了錯。

③ It seems + likely / possible + that + 子句

  1. It seems likely that the shop will close soon.
    那家店看起來很可能很快就會關門。
  2. It seems possible that robots will do many of our jobs.
    機器人看起來有可能會做我們很多工作。
  3. It seems likely that the bad weather will continue into next week.
    壞天氣看起來很可能會持續到下星期。
  4. It seems possible that the two problems are connected.
    這兩個問題看起來有可能有關。
  5. It seems likely that the minister will resign.
    部長看起來很可能會辭職。
  6. It seems possible that we misunderstood each other.
    我們看起來有可能誤會了彼此。
  7. It seems likely that the twins will go to different schools.
    雙胞胎看起來很可能會念不同的學校。

④ 否定：It does not seem / is not + possible / likely + that + 子句

  1. It does not seem possible that prices will fall soon.
    物價似乎不可能很快下跌。
  2. It doesn't seem likely that he will change his mind.
    他似乎不太可能改變主意。
  3. It is not likely that the factory will reopen.
    工廠不太可能重新開工。
  4. It doesn't seem possible that she is already forty.
    她似乎不可能已經四十歲了。
  5. It is not possible that everyone will agree.
    不可能每個人都同意。
  6. It does not seem likely that the plan will succeed.
    這個計畫似乎不太可能成功。
  7. It isn't likely that we'll see snow this winter.
    今年冬天不太可能看到雪。
  8. It doesn't seem possible that the work can be done in a week.
    這項工作似乎不可能在一個星期內完成。（被動）
