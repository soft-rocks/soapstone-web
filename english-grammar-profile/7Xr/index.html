Would you like to buy this book?

你想買這本書嗎？

this + 名⁠詞

Would you like to buy this book?

你想買這本書嗎？

this 指⁠的東⁠西

Would you like to buy this book?

手上拿的

This phone has a cracked screen.

這支手機的螢幕裂了。
身邊的

Is this chair broken?

這張椅子壞了嗎？
正在寫的

I'm sending this email from my phone.

我用手機寄這封電子郵件。
自己給的

You can call me on this number.

你可以打這個號碼給我。

寫⁠信⁠時用 this

Would you like to buy this book?

開頭

I am writing this letter to thank you for the present.

我寫這封信，是要謝謝你送的禮物。
結尾

I hope this information helps you.

希望這個資料對你有幫助。

this 指近⁠的，that 指遠⁠的

Would you like to buy this book?

this book說話的人手上的書
that book架子上離說話的人遠的書

手⁠上⁠的東⁠西用 this

Would you like to buy this book?

Look at that ring on my finger.

Look at this ring on my finger.

正⁠在寫⁠的信⁠用 this

Would you like to buy this book?

I am writing the letter to say thank you.

I am writing this letter to say thank you.

複⁠數名⁠詞前⁠面用 these

Would you like to buy this book?

Would you like to buy this books?

Would you like to buy these books?

this 和 my 不⁠一⁠起用

Would you like to buy this book?

This my phone is new.

This phone is new.

例句

① 在店裡

  1. I'd like to pay for this jacket by card.
    這件夾克我想刷卡。
  2. Does this skirt come in blue?
    這件裙子有藍色的嗎？
  3. This one looks nice. I'll take it.
    這個看起來不錯。我要買這個。
  4. This vase is a hundred years old.
    這個花瓶有一百年的歷史了。
  5. Would you like to try this cake? It's new.
    你想試吃這個蛋糕嗎？這是新口味。

② 手上的東西

  1. This pencil is broken. Have you got another one?
    這支鉛筆斷了。你有別支嗎？
  2. Look at this photo of my cat.
    你看這張我家貓的照片。
  3. Can you open this jar for me?
    你可以幫我打開這個罐子嗎？
  4. This key doesn't open the door.
    這把鑰匙打不開門。
  5. Smell this flower. It's lovely.
    你聞聞這朵花。很香。

③ 身邊的東西

  1. This sofa is too soft for my back.
    這張沙發太軟，對我的背不好。
  2. This lamp is too bright for the bedroom.
    這盞燈放在臥室太亮了。
  3. This computer takes ages to start.
    這台電腦開機要好久。
  4. Who left this window open?
    這扇窗戶是誰沒關的？

④ 寫信時指正在寫的信

  1. I am writing this letter to tell you about my new school.
    我寫這封信，是要跟你說我的新學校。
  2. I'm sending this email from the airport.
    我在機場寄這封電子郵件。
  3. Please answer this message soon.
    請快點回這則訊息。
  4. I am writing this note because you were out.
    你不在，所以我寫了這張字條。
  5. I hope you like this postcard from Paris.
    希望你喜歡這張從巴黎寄來的明信片。

⑤ 信的結尾

  1. I hope this information is useful.
    希望這個資料對你有用。
  2. Read this letter when you feel sad.
    你難過的時候就讀讀這封信。
  3. Thank you for reading this email.
    謝謝你讀這封電子郵件。
  4. Write back and tell me what you think of this idea.
    回信告訴我你覺得這個主意怎麼樣。

⑥ 給號碼和地址

  1. You can contact me by calling me on this number.
    你可以打這個號碼聯絡我。
  2. Please send the parcel to this address.
    請把包裹寄到這個地址。
  3. My new email is on this card.
    我的新電子郵件地址寫在這張卡片上。
  4. Click on this link to see the photos.
    點這個連結就可以看照片。

⑦ 介紹禮物和自己的東西

  1. My aunt gave me this bracelet for my birthday.
    我阿姨送我這個手環當生日禮物。
  2. This laptop was my favourite birthday present.
    這台筆電是我最喜歡的生日禮物。
  3. My grandmother knitted this scarf for me.
    這條圍巾是我奶奶織給我的。
  4. My best friend sent me this hat from Peru.
    我最好的朋友從秘魯寄這頂帽子給我。
  5. My grandfather wore this watch every day.
    我爺爺以前每天都戴這支手錶。
