It's going to be in São Paulo. Should we go by plane?

我應該穿特別的衣服嗎？

Should + 主⁠詞 + 原⁠形⁠動⁠詞 + …？

Should I / we我／我們應該……嗎？
疑問詞what、where、when、how 放在句首。
原形動詞問的那件事。

問該怎⁠麼做

It's going to be in São Paulo. Should we go by plane?

例句

What should I wear to the party?

我去派對應該穿什麼？

疑問詞放在 should 前面，問具體的做法。

should 的問⁠句不⁠用 do

It's going to be in São Paulo. Should we go by plane?

Do I should wear a tie?

Should I wear a tie?

疑⁠問⁠詞後⁠面先放 should，再放主⁠詞

It's going to be in São Paulo. Should we go by plane?

What I should bring?

What should I bring?

should 後⁠面直⁠接接原⁠形⁠動⁠詞

It's going to be in São Paulo. Should we go by plane?

Should we to go by train?

Should we go by train?

例句

① Should we + 原形動詞？：問交通和安排

  1. The festival is going to be in São Paulo. Should we go by plane or take the bus?
    音樂節在聖保羅。我們應該搭飛機去還是搭巴士？
  2. The film starts at eight. Should we eat before or after it?
    電影八點開始。我們應該在電影之前還是之後吃飯？
  3. It's going to rain all day. Should we cancel the picnic?
    整天都會下雨。我們應該取消野餐嗎？
  4. The hotel is quite far from the station. Should we book a taxi?
    飯店離車站很遠。我們應該叫計程車嗎？
  5. The queue for the castle is huge. Should we come back tomorrow morning?
    排城堡的隊伍好長。我們應該明天早上再來嗎？
  6. My brother wants to come too. Should we buy three tickets?
    我哥哥也想來。我們應該買三張票嗎？

② Should I + 原形動詞？：問自己應不應該做

  1. It's a formal dinner. Should I wear special clothes?
    那是正式的晚宴。我應該穿特別的衣服嗎？
  2. The teacher looked angry. Should I say sorry to her after class?
    老師看起來很生氣。下課後我應該跟她道歉嗎？
  3. My phone is very old. Should I buy a new one or repair it?
    我的手機很舊了。我應該買新的還是修理？
  4. I've got a sore throat. Should I stay at home tomorrow?
    我喉嚨痛。我明天應該待在家裡嗎？
  5. My friend hasn't answered my message. Should I call her?
    我朋友沒回我的訊息。我應該打給她嗎？
  6. The job pays well but it's far away. Should I take it?
    那份工作薪水很好，可是很遠。我應該接受嗎？

③ What should I / we + 原形動詞？

  1. I'm going to an interview tomorrow. What should I say about my last job?
    我明天要去面試。關於我上一份工作，我應該說什麼？
  2. It's Dad's birthday next week. What should we get him?
    下星期是爸爸的生日。我們應該送他什麼？
  3. We're going camping. What should we take with us?
    我們要去露營。我們應該帶什麼？
  4. I've burnt the rice. What should I do now?
    我把飯煮焦了。我現在應該怎麼辦？
  5. I don't know anyone at the party. What should I talk about?
    我在派對上一個人都不認識。我應該聊什麼？
  6. My plant has yellow leaves. What should I give it?
    我的植物葉子變黃了。我應該給它什麼？

④ Where / When / How + should + 主詞 + 原形動詞？

  1. We've got three days in Rome. Where should we stay?
    我們在羅馬有三天。我們應該住哪裡？
  2. The exam is in May. When should I start revising?
    考試在五月。我應該什麼時候開始複習？
  3. I've never cooked fish before. How should I cook it?
    我從來沒煮過魚。我應該怎麼煮？
  4. The new sofa is very big. Where should we put it?
    新沙發很大。我們應該把它放在哪裡？
  5. The party is on Friday. When should we send the invitations?
    派對在星期五。我們應該什麼時候寄邀請函？
  6. I want to improve my English. How should I practise?
    我想讓我的英文進步。我應該怎麼練習？

⑤ Do you think + 主詞 + should + 原形動詞？：客氣地問意見

  1. Do you think I should cut my hair short for the summer?
    你覺得我夏天應該把頭髮剪短嗎？
  2. Do you think we should invite the new neighbours to the barbecue?
    你覺得我們應該邀請新鄰居來烤肉嗎？
  3. Do you think she should tell her parents about the accident?
    你覺得她應該把那次意外告訴她爸媽嗎？
  4. Do you think I should learn Spanish or Italian first?
    你覺得我應該先學西班牙文還是義大利文？
  5. Do you think we should paint the kitchen white?
    你覺得我們應該把廚房漆成白色嗎？
  6. Do you think he should apply for the manager's job?
    你覺得他應該去應徵經理的工作嗎？
  7. Do you think they should sell the old car?
    你覺得他們應該把那台舊車賣掉嗎？
