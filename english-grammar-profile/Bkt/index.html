I'm going to find more information about the new art class.

我要去多找一些新美術課的資料。

不⁠可⁠數⁠名⁠詞用數⁠量詞說數⁠量

我要去多找一些新美術課的資料。

some 用在肯⁠定⁠句，any 用在否⁠定⁠句，a lot of 和 more 說量多

例句

① some + 不可數名詞

  1. I can't go out tonight. It's really important, because I need to do some homework.
    我今晚不能出去，這很重要，因為我得寫一些功課。
  2. Could you lend me some money for the bus?
    你可以借我一點錢搭公車嗎？
  3. We need some milk and some bread from the shop.
    我們需要去商店買點牛奶和麵包。
  4. There's some soup on the stove if you get hungry later.
    你等一下餓的話，爐子上有一些湯。

② any + 不可數名詞

  1. Now I haven't got any money, but I'm really happy!
    我現在一毛錢都沒有，可是我好開心！
  2. Is there any coffee left in the pot?
    壺裡還有咖啡嗎？
  3. We didn't have any rain on holiday.
    我們度假的時候一滴雨都沒下。
  4. Do you need any help with the cooking?
    你煮飯需要幫忙嗎？

③ a lot of / lots of + 不可數名詞

  1. We had a lot of fun at the party.
    我們在派對上玩得很開心。
  2. There's a lot of traffic on the way to the airport.
    去機場的路上車很多。
  3. My grandma puts lots of sugar in her tea.
    我奶奶喝茶加很多糖。
  4. I spent a lot of money on presents this year.
    我今年花了很多錢買禮物。

④ more + 不可數名詞

  1. I phoned the college for more information about the art class.
    我打電話到學院問更多美術課的資訊。
  2. This curry is delicious. Is there any more rice?
    這咖哩好好吃，還有飯嗎？
  3. The garden looks dry. The plants need more water this week.
    院子看起來好乾，植物這個禮拜需要多澆點水。
  4. We need more time to finish the project.
    我們需要更多時間完成這個專題。

⑤ 疑問句裡的 any 和 some

  1. Have you got any homework tonight?
    你今晚有功課嗎？
  2. Is there any milk in the fridge?
    冰箱裡有牛奶嗎？
  3. Could you bring us some more bread for the table?
    可以再給我們這桌一些麵包嗎？
  4. Shall I get some ice for the drinks?
    要不要我去拿一些冰塊加在飲料裡？

⑥ 否定句裡的 any

  1. Sorry, I don't have any change for the parking machine.
    抱歉，我沒有零錢可以付停車費。
  2. There isn't any bread for breakfast.
    早餐沒有麵包了。
  3. We haven't got any furniture in the new flat yet.
    我們的新公寓還沒有任何家具。
  4. He didn't give me any advice.
    他沒給我任何建議。

⑦ 數量詞 + 不可數名詞當主詞

  1. Some money is missing from my purse.
    我錢包裡少了一些錢。
  2. A lot of rain fell in the night.
    夜裡下了很多雨。
  3. More information is on our website.
    更多資訊在我們的網站上。
  4. Lots of water came into the kitchen.
    很多水流進了廚房。

⑧ 數量詞 + 形容詞 + 不可數名詞

  1. I bought some fresh bread for lunch.
    我買了一些新鮮麵包當午餐。
  2. We need a lot of hot water for the bath.
    洗澡需要很多熱水。
  3. Do you have any good advice for me?
    你有什麼好建議可以給我嗎？
