I knew I should have written before.

你當時真該跟我們在一起。

主⁠詞 + should have + 過⁠去⁠分⁠詞

should have、過⁠去⁠分⁠詞

should have過去應該。事情沒有做。
過去分詞過去應該做的事。

縮⁠寫

I knew I should have written before.

例句

You should've told me.

你應該早點告訴我的。

口語常把 should have 說成 should've。

You should have been …

例句

You should have been with us at the party.

你當時應該跟我們一起去派對的。

You should have been 常用來說「你當時應該在場」，因為那時很好玩或很精彩。

have 後⁠面⁠接過⁠去⁠分⁠詞

I knew I should have written before.

I should have write to you.

I should have written to you.

should've 聽⁠起⁠來像 should of，可⁠是要⁠寫 should have

I knew I should have written before.

You should of called me.

You should have called me.

should 後⁠面⁠接原⁠形 have

I knew I should have written before.

We should had left earlier.

We should have left earlier.

例句

① I should have + 過去分詞：自己沒做的事

  1. Sorry I haven't written for three months. I knew I should have written before.
    抱歉我三個月沒寫信。我知道我早就應該寫信了。
  2. I failed the test. I should have studied harder.
    我考試沒過。我應該更用功的。
  3. I'm so cold. I should have brought a warmer coat.
    我好冷。我應該帶一件更暖的外套的。
  4. I should have listened to my dad. He was right about the car.
    我應該聽我爸爸的話。他對那台車的看法是對的。
  5. The shop is closed now. I should have gone this morning.
    那家店現在關了。我應該早上去的。
  6. I should have checked the time of the last bus.
    我應該查一下最後一班公車的時間的。

② You should have been + with us / there：當時應該在場

  1. The concert was amazing. You should have been with us!
    音樂會太精彩了。你當時應該跟我們一起去的！
  2. You should have been at the beach yesterday. The sea was so warm.
    你昨天應該在海灘的。海水好溫暖。
  3. You should have been there when Tom fell in the pool!
    湯姆掉進游泳池的時候，你應該在場的！
  4. The food at the wedding was wonderful. You should have been there.
    婚禮的食物太棒了。你應該去的。
  5. You should have been at the match. It was the best game of the season.
    你應該去看那場比賽的。那是這一季最好的比賽。
  6. We had such a laugh last night. You should have been with us.
    我們昨晚笑得好開心。你應該跟我們在一起的。

③ You should have + 過去分詞：說對方當時應該做的事

  1. Why didn't you ask me? You should have told me you needed money.
    你為什麼不問我？你需要錢的時候應該告訴我的。
  2. You should have taken the train. The roads were terrible.
    你應該搭火車的。路況很糟。
  3. You should have called before you came. I was out.
    你來之前應該先打電話的。我那時不在。
  4. You should have worn a hat. Your face is all red.
    你應該戴帽子的。你的臉都紅了。
  5. You should have asked for a receipt.
    你應該要收據的。
  6. You should have seen a doctor sooner.
    你應該早點去看醫生的。

④ We / They + should have + 過去分詞

  1. We missed the plane. We should have left home earlier.
    我們錯過了飛機。我們應該早點出門的。
  2. They should have booked a hotel. Everything was full.
    他們應該訂飯店的。全都客滿了。
  3. We should have bought more bread. There's none left.
    我們應該多買點麵包的。都沒了。
  4. They should have read the instructions before they started.
    他們開始之前應該先讀說明的。
  5. We should have taken a photo of the sunset.
    我們應該拍一張夕陽的照片的。
  6. They should have asked for directions at the station.
    他們應該在車站問路的。

⑤ 主詞 + should have + 過去分詞 + by now：現在應該已經

  1. The parcel should have arrived by now. Let's call the shop.
    包裹現在應該已經到了。我們打電話給那家店吧。
  2. It's after seven. Dad should have got home by now.
    已經七點多了。爸爸現在應該已經到家了。
  3. The cake has been in the oven for an hour. It should have finished baking by now.
    蛋糕在烤箱裡一個小時了。現在應該已經烤好了。
  4. They left at noon, so they should have reached the hotel by now.
    他們中午出發，所以現在應該已經到飯店了。
  5. The results should have come out by now.
    結果現在應該已經出來了。
  6. The snow should have melted by now. It's April.
    雪現在應該已經融化了。都四月了。
  7. My sister should have finished her exams by now.
    我姊姊現在應該已經考完試了。
