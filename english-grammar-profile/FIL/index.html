If I had worn uncomfortable shoes, I wouldn't have danced all night.

要不是你幫我，我根本不知道那份專題作業要怎麼做。

If + 主⁠詞 + had + 過⁠去⁠分⁠詞, + 主⁠詞 + would (not) have + 過⁠去⁠分⁠詞

if … had和過去事實相反的條件。
would have想像中過去的結果。

If I were in your shoes

例句

If I were in your shoes, I would have chosen the city school.

如果我是你，我會選城裡那所學校。

If I were in your shoes 意思是「如果我是你」，說自己在對方的情況下會怎麼做。

想⁠像⁠的經⁠歷

例句

The next week I would have flown to Miami.

下個星期我本來會飛去邁阿密。

would have 也可以說想像中原本會發生的經歷。

if 子⁠句用 had 加過⁠去⁠分⁠詞

If I had worn uncomfortable shoes, I wouldn't have danced all night.

If you would have helped me, I would have finished.

If you had helped me, I would have finished.

have 後⁠面⁠接過⁠去⁠分⁠詞

If I had worn uncomfortable shoes, I wouldn't have danced all night.

I wouldn't have knew how to do it.

I wouldn't have known how to do it.

過⁠去⁠分⁠詞前⁠面要⁠有 had

If I had worn uncomfortable shoes, I wouldn't have danced all night.

If I gone with you, I would have enjoyed it.

If I had gone with you, I would have enjoyed it.

例句

① If + 主詞 + had + 過去分詞, + 主詞 + wouldn't have + 過去分詞

  1. I chose flat shoes for the wedding. If I had gone in uncomfortable shoes, I wouldn't have danced all night.
    我穿了平底鞋去婚禮。如果我穿了不舒服的鞋子，我就不會整晚都在跳舞了。
  2. If you hadn't helped me, I wouldn't have known how to do that homework project.
    如果你沒幫我，我就不會知道怎麼做那份作業。
  3. If we hadn't taken a taxi, we wouldn't have arrived on time.
    如果我們沒搭計程車，就不會準時到了。
  4. If she hadn't called me, I wouldn't have known about the party.
    如果她沒打給我，我就不會知道派對的事。
  5. If the guide hadn't come back for us, we wouldn't have found the path in the dark.
    如果導遊沒回來找我們，我們在黑暗中就找不到步道了。
  6. If they hadn't booked early, they wouldn't have got a table.
    如果他們沒早點訂位，就不會有位子了。

② If I were in your shoes, + I would have + 過去分詞

  1. If I were in your shoes, I would have chosen the school in the centre of town.
    如果我是你，我會選市中心那所學校。
  2. If I were in your shoes, I would have told her the truth.
    如果我是你，我會告訴她真相。
  3. If I were in your shoes, I would have asked for a refund.
    如果我是你，我會要求退款。
  4. If I were in your shoes, I would have taken the job in Paris.
    如果我是你，我會接受巴黎那份工作。
  5. If I were in your shoes, I would have called the police.
    如果我是你，我會報警。
  6. If I were in your shoes, I would have stayed at home.
    如果我是你，我會待在家裡。

③ 主詞 + would have + 過去分詞：想像中原本的經歷

  1. In my dream I won a competition. The next week I would have flown to Miami to meet a famous actor.
    在我的夢裡我贏了一場比賽。下個星期我本來會飛去邁阿密見一位有名的演員。
  2. With the prize money, I would have bought a house by the sea.
    有了那筆獎金，我本來會在海邊買一間房子。
  3. In that job, I would have travelled all over Europe.
    做那份工作，我本來會到歐洲各地旅行。
  4. On the first day of the trip, we would have visited the castle.
    旅行的第一天，我們本來會去參觀城堡。
  5. As team captain, she would have led the team onto the field.
    身為隊長，她本來會帶領球隊進場。
  6. With a bigger car, we would have taken the whole family.
    有大一點的車，我們本來會帶全家去。

④ If + 主詞 + had + 過去分詞, + 主詞 + would have + 過去分詞

  1. If I had known you were coming, I would have made a cake.
    如果我知道你要來，我就會做一個蛋糕。
  2. If we had left earlier, we would have seen the start of the show.
    如果我們早點出發，就會看到表演的開頭了。
  3. If he had listened to his coach, he would have won the race.
    如果他聽了教練的話，他就會贏得比賽了。
  4. If it had snowed, we would have gone skiing.
    如果下雪了，我們就會去滑雪了。
  5. If she had studied French, she would have understood the film.
    如果她學過法文，她就會看懂那部電影了。
  6. If they had asked, I would have helped them.
    如果他們問了，我就會幫他們了。

⑤ 主詞 + would have + 過去分詞 + if + 子句：if 子句放在後面

  1. I would have called you if I had had your number.
    如果我有你的電話號碼，我就會打給你了。
  2. We would have stayed longer if the weather had been better.
    如果天氣好一點，我們就會待久一點了。
  3. She would have come to the party if she had felt better.
    如果她覺得好一點，她就會來派對了。
  4. They would have bought the house if it had been cheaper.
    如果那間房子便宜一點，他們就會買了。
  5. I would have taken a photo if I had had my camera.
    如果我帶了相機，我就會拍照了。
  6. He would have passed the test if he had read the questions carefully.
    如果他仔細讀題目，他就會通過考試了。
  7. We would have missed the train if you hadn't woken us up.
    如果你沒叫醒我們，我們就會錯過火車了。
