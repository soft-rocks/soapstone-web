This is the best holiday I have ever had!

this 常指⁠的事

This is the best holiday I have ever had!

活動

This is so much fun! Let's do it again tomorrow.

這好好玩！我們明天再來一次。
信或留言

This is just a short note to say thank you.

寫這張短箋只是想跟你說聲謝謝。
電話

Hello, this is Maria. Can I speak to Anna?

喂，我是瑪麗亞。請問安娜在嗎？

this 現⁠在，that 過⁠去

This is the best holiday I have ever had!

現在

This is a great party.

這個派對很棒。
過去

That was a great party.

那個派對很棒。

現⁠在⁠的事用 this

This is the best holiday I have ever had!

I'm sitting on the beach. That is wonderful!

I'm sitting on the beach. This is wonderful!

電⁠話⁠裡用 this is

This is the best holiday I have ever had!

Hello, I am Peter. Is Tom there?

Hello, this is Peter. Is Tom there?

一⁠件⁠事用單⁠數 this

This is the best holiday I have ever had!

We're at the zoo today. These is great!

We're at the zoo today. This is great!

this + 名⁠詞

這家旅館很舒服。

it：不⁠指任⁠何東⁠西

又在下雨了。

例句

① 度假的時候

  1. We're in Rome! This is amazing.
    我們在羅馬！太棒了。
  2. Sun, sea and good food. This is the life!
    陽光、大海、美食，這才叫生活！
  3. The hotel has two pools. This is like a dream!
    這家旅館有兩個游泳池，簡直像在作夢！
  4. This is our third day in the mountains, and we love it.
    這是我們在山上的第三天，我們很喜歡。
  5. This is my first time abroad. Everything is new.
    這是我第一次出國，一切都很新鮮。

② 正在做的事

  1. Come and try the new game. This is so cool!
    來試試這個新遊戲，好酷！
  2. This is taking too long. Let's ask someone.
    這花太久時間了，我們找人問問吧。
  3. We're baking a cake together. This is fun!
    我們正在一起做蛋糕，好好玩！
  4. This is harder than I thought.
    這比我想的還難。
  5. I'm learning to ski. This is really difficult!
    我在學滑雪，真的好難！

③ 寫信和留言

  1. This is just a short note to ask you if you want to go with me to the ReggaRton's concert.
    寫這張短箋是想問你要不要跟我去看 ReggaRton 的演唱會。
  2. Sorry, this is a really long email!
    抱歉，這封電子郵件好長！
  3. This is to say that the meeting has moved to Friday.
    這封信是要通知大家，會議改到星期五。
  4. This is my first email in English, so please be kind!
    這是我第一封英文電子郵件，請多包涵！
  5. Hi Sam, this is a quick message from the train.
    嗨，山姆，我在火車上傳個簡短訊息給你。

④ 打電話

  1. Hi, this is Laura from the dentist's.
    你好，我是牙醫診所的蘿拉。
  2. Hello, is this the police station?
    喂，請問是警察局嗎？
  3. This is Mark. I'm calling about the flat.
    我是馬克，我打來是想問公寓的事。
  4. "Who's calling, please?" "This is Mrs Clark."
    請問是哪位？我是克拉克太太。
  5. Hi Dad, this is me. Can you pick me up?
    爸，是我。你可以來接我嗎？

⑤ 對現在的感受

  1. This is the best day of my life!
    這是我這輩子最棒的一天！
  2. Oh no, this is terrible. The shop is closed.
    喔不，真糟糕。店關門了。
  3. This is so boring. When does the film end?
    好無聊喔，電影什麼時候結束？
  4. Wow, this is delicious! What's in it?
    哇，好好吃！裡面放了什麼？
  5. This is crazy. There are so many people here!
    太誇張了，這裡好多人！

⑥ 介紹和說明

  1. Welcome, everyone. This is a very special evening for our school.
    歡迎各位，今晚對我們學校來說是很特別的一晚。
  2. This is your captain speaking. We will land in twenty minutes.
    我是機長，我們將在二十分鐘後降落。
  3. This is the first time we've all been together for years.
    這是我們好幾年來第一次全部聚在一起。
  4. Listen, everyone. This is important.
    大家聽好，這件事很重要。
  5. This is the news at six o'clock.
    六點新聞時間到了。
  6. Thank you all for coming. This is a big moment for our family.
    謝謝大家來，這對我們家來說是重要的時刻。
