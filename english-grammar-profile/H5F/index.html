It had been snowing for a long time, and so I was unable to go out for a walk.

雪已經下了很久，所以我沒辦法出去散步。

主⁠詞 + had been + ⁠-⁠ing, + so + 主⁠詞 + 過⁠去⁠式

had been + -⁠ing持續一段時間的事。
so / because連接原因和結果。
過去式結果。

看得⁠到⁠的結⁠果

例句

We had been working hard all morning, so by lunchtime I was very tired.

我們一整個早上都工作得很辛苦，所以到午餐時我很累。

這個句型常說看得到的結果，像累、髒、濕。

結⁠果比動⁠作重⁠要

例句

Her eyes were red. She had been crying.

她的眼睛紅紅的。她剛剛一直在哭。

說話者想強調的是結果。動作本身可能已經停了。

結⁠果用過⁠去⁠式

It had been snowing, so I had been staying inside.

It had been snowing, so I stayed inside.

been 前⁠面要⁠有 had

It had been snowing for a long time, and so I was unable to go out for a walk.

She been running, so she was out of breath.

She had been running, so she was out of breath.

說過⁠去⁠的事用 had been

It had been snowing for a long time, and so I was unable to go out for a walk.

Last night he has been working, so he was tired.

Last night he had been working, so he was tired.

例句

① 主詞 + had been + -ing, so + 主詞 + 過去式：天氣的結果

  1. When I woke up in the cabin, it had been snowing for a long time, and so I was unable to go out for a walk.
    我在小屋醒來的時候，雪已經下了很久，所以我沒辦法出去散步。
  2. It had been raining all night, so the football pitch was too wet to play on.
    下了一整晚的雨，所以足球場太濕了，不能踢球。
  3. The wind had been blowing for days, so the ferry stayed in the harbour.
    風颳了好幾天，所以渡輪一直停在港口。
  4. It had been freezing all week, so the lake was covered in ice.
    冷了一整個星期，所以湖面都結冰了。
  5. The sun had been shining all day, so the sand was very hot.
    太陽照了一整天，所以沙子很燙。
  6. It had been snowing since morning, so the schools closed early.
    從早上就一直下雪，所以學校提早放學了。

② 主詞 + had been + -ing + all + 時間, so + 主詞 + was + 形容詞

  1. We had been working very hard all morning, so by lunchtime I was very tired.
    我們一整個早上都工作得很辛苦，所以到午餐時我很累。
  2. She had been dancing all night, so her feet were sore.
    她跳了一整晚的舞，所以她的腳很痛。
  3. They had been walking in the hills all day, so they were hungry.
    他們在山丘上走了一整天，所以很餓。
  4. I had been studying all weekend, so my head was spinning.
    我讀了一整個週末的書，所以頭昏腦脹。
  5. He had been gardening all afternoon, so his hands were dirty.
    他整個下午都在整理花園，所以他的手很髒。
  6. The children had been playing outside all day, so they were covered in mud.
    孩子們在外面玩了一整天，所以全身都是泥巴。

③ 主詞 + 過去式. + 主詞 + had been + -ing：看到結果，推出原因

  1. My sister's face was pink and her hair was wet. She had been swimming in the lake.
    我妹妹的臉紅紅的，頭髮是濕的。她剛剛一直在湖裡游泳。
  2. The kitchen was full of smoke. Someone had been cooking.
    廚房裡都是煙。剛剛有人在煮東西。
  3. My brother's shirt was soaked with sweat. He had been playing tennis in the heat.
    我哥哥的襯衫被汗濕透了。他剛剛一直在大熱天打網球。
  4. There were puddles all over the car park. It had been pouring all morning.
    停車場到處都是水坑。整個早上一直在下大雨。
  5. The room smelt of paint. They had been decorating.
    房間裡有油漆味。他們剛剛一直在裝修。
  6. Her clothes were covered in flour. She had been baking.
    她的衣服沾滿了麵粉。她剛剛一直在烤東西。

④ 主詞 + 過去式 + because + 主詞 + had been + -ing

  1. The roads were dangerous because it had been snowing all night.
    路很危險，因為下了一整晚的雪。
  2. I failed the test because I hadn't been revising.
    我考試沒過，因為我一直沒複習。
  3. He had a sore throat because he had been shouting at the match.
    他喉嚨痛，因為他在比賽時一直在大喊。
  4. The baby was hungry because she had been sleeping for hours.
    寶寶很餓，因為她睡了好幾個小時。
  5. My back hurt because I had been carrying heavy boxes.
    我的背很痛，因為我一直在搬很重的箱子。
  6. The car was hot because it had been standing in the sun.
    車子很熱，因為它一直停在太陽下。

⑤ By + 時間, + 主詞 + had been + -ing, so + 主詞 + 過去式

  1. By the evening, we had been travelling for twelve hours, so we went straight to bed.
    到了傍晚，我們已經旅行了十二個小時，所以直接上床睡覺了。
  2. By the end of the match, the players had been running for ninety minutes, so they were exhausted.
    到比賽結束的時候，球員們已經跑了九十分鐘，所以累壞了。
  3. By Friday, I had been working late every night, so I slept all weekend.
    到星期五的時候，我每天晚上都加班，所以整個週末都在睡覺。
  4. By midnight, the guests had been eating and drinking for hours, so the party was very loud.
    到半夜的時候，客人們已經吃喝了好幾個小時，所以派對很吵。
  5. By the summer, he had been saving for a year, so he could buy the bike.
    到夏天的時候，他已經存了一年的錢，所以他買得起那台腳踏車。
  6. By ten o'clock, it had been raining for six hours, so the river was very high.
    到十點的時候，已經下了六個小時的雨，所以河水很高。
  7. By the time the exam came, she had been practising for months, so she felt calm.
    到考試的時候，她已經練習了好幾個月，所以她覺得很冷靜。
