I think this Saturday is going to be a nice day.

我覺得這個星期六天氣會很好。

主⁠詞 + am / is / are + going to be + 形⁠容⁠詞 / 名⁠詞

I think this Saturday is going to be a nice day.

be going to表示預測。
begoing to 後面的動詞是 be。
形容詞 / 名詞預測的情況，像 fantastic、hot、a nice day、great fun。

be 後⁠面⁠接形⁠容⁠詞

例句

It's going to be fantastic.

一定會很棒。

be 後⁠面⁠接名⁠詞

例句

It's going to be great fun.

一定會很好玩。

根⁠據眼⁠前⁠的情⁠況預⁠測

例句

Look at those clouds. It's going to be a wet afternoon.

你看那些雲，下午會下雨。

說話者看到眼前的情況，預測接下來會怎樣。

going to 後⁠面⁠接形⁠容⁠詞⁠時，中⁠間要⁠有 be

I think this Saturday is going to be a nice day.

It's going to fantastic.

It's going to be fantastic.

to 後⁠面⁠的 be 用原⁠形

I think this Saturday is going to be a nice day.

The party is going to is great.

The party is going to be great.

going to 前⁠面要⁠有 am、is 或 are

I think this Saturday is going to be a nice day.

This film going to be boring.

This film is going to be boring.

例句

① be going to be + 形容詞

  1. With all our friends there, the holiday is going to be fantastic.
    所有朋友都會去，這次假期一定會很棒。
  2. You should wear comfortable clothes because you are going to be hot.
    你應該穿舒服一點的衣服，因為你會很熱。
  3. The exam is going to be difficult.
    考試會很難。
  4. Tomorrow is going to be cold and windy.
    明天會又冷又有風。
  5. The roads are going to be busy this weekend.
    這個週末路上車會很多。
  6. Your mum is going to be angry.
    你媽媽會很生氣。
  7. The kids are going to be tired after the trip.
    孩子們旅行回來會很累。
  8. This winter is going to be very long.
    今年冬天會很漫長。
  9. The meeting is going to be short today.
    今天的會議會很短。
  10. I'm going to be late again.
    我又要遲到了。
  11. The new teacher is going to be strict.
    新老師會很嚴格。
  12. The tickets are going to be expensive.
    票會很貴。
  13. Dinner is going to be ready soon.
    晚餐很快就好了。
  14. The beach is going to be crowded on Sunday.
    星期天海灘會很擠。
  15. She's going to be so happy when she hears the news.
    她聽到這個消息一定會很開心。
  16. Don't take the kids to that film, because it's going to be too scary for them.
    別帶孩子們去看那部電影，那對他們來說會太恐怖。

② be going to be + 名詞

  1. The school trip to the zoo is going to be great fun for the kids.
    去動物園的校外教學對孩子們來說一定會很好玩。
  2. Saturday is going to be a busy day.
    星期六會是忙碌的一天。
  3. With three essays to write, it's going to be a long night for me.
    要寫三篇作文，今晚對我來說會很漫長。
  4. This is going to be the best party ever.
    這會是有史以來最棒的派對。
  5. The match is going to be a hard one.
    這場比賽會很難打。
  6. Our new neighbour is going to be a problem.
    我們的新鄰居會是個麻煩。
  7. She's going to be a great teacher one day.
    她有一天會成為很棒的老師。
  8. Look at the sky, it's going to be a beautiful sunset over the sea.
    你看天空，等一下海上會有很美的夕陽。
  9. The concert is going to be a big success.
    音樂會一定會很成功。
  10. This summer is going to be a hot one.
    今年夏天會很熱。
  11. The new shopping centre is going to be a big help for the town.
    新的購物中心對這個鎮會有很大的幫助。
  12. According to the forecast, tomorrow is going to be the hottest day of the year.
    根據氣象預報，明天會是今年最熱的一天。
  13. Learning to drive is going to be a challenge for him.
    學開車對他來說會是一大挑戰。
  14. The test is going to be a piece of cake.
    這次考試會很簡單。
  15. Next year is going to be an exciting year for us.
    明年對我們來說會是令人興奮的一年。
