If the weather had been better, we would have enjoyed it more.

要是那時天氣好一點，我們就會玩得更開心。

If + 主⁠詞 + had + 過⁠去⁠分⁠詞, + 主⁠詞 + would have + 過⁠去⁠分⁠詞

if + had + 過去分詞和過去事實相反的條件。
would have + 過去分詞想像中的結果。

遺⁠憾

例句

If you had come with me, you would have been happy.

如果你跟我一起去，你會很開心。（可惜你沒去）

這個句型常用來說遺憾。

if 子⁠句放⁠在⁠後⁠面

If the weather had been better, we would have enjoyed it more.

例句

I would have stayed all night if the park hadn't closed.

如果公園沒關門，我會待一整晚。

if 子句可以放在句子後面。

if 子⁠句用 had 加過⁠去⁠分⁠詞

If the weather had been better, we would have enjoyed it more.

If the weather would have been better, we would have enjoyed it.

If the weather had been better, we would have enjoyed it.

說過⁠去想⁠像⁠的情⁠況用 had 加過⁠去⁠分⁠詞

If the weather had been better, we would have enjoyed it more.

If you came with me yesterday, you would have been happy.

If you had come with me yesterday, you would have been happy.

had 後⁠面⁠接過⁠去⁠分⁠詞

If the weather had been better, we would have enjoyed it more.

If I had went earlier, I would have seen her.

If I had gone earlier, I would have seen her.

例句

① If + 主詞 + had been + 形容詞, + 主詞 + would have + 過去分詞

  1. It rained every day of our holiday. If the weather had been better, we would have enjoyed it more.
    我們度假的每一天都在下雨。如果天氣好一點，我們會玩得更開心。
  2. If the hotel had been cleaner, we would have stayed longer.
    如果飯店乾淨一點，我們就會待久一點。
  3. If the tickets had been cheaper, more people would have come.
    如果票便宜一點，就會有更多人來。
  4. If the film had been shorter, the children would have enjoyed it.
    如果電影短一點，孩子們就會喜歡。
  5. If the water had been warmer, we would have gone swimming.
    如果水暖一點，我們就會去游泳。
  6. If the road had been safer, the accident wouldn't have happened.
    如果那條路安全一點，意外就不會發生。

② If you had + 過去分詞, + you would have + 過去分詞：可惜對方沒做

  1. The concert was amazing. If you had gone there with me, you would have been so happy.
    演唱會太棒了。如果你跟我一起去，你一定會很開心。
  2. If you had joined the choir, you would have sung at the cathedral.
    如果你加入了合唱團，你就會在大教堂唱歌了。
  3. If you had studied harder, you would have passed the exam.
    如果你更用功，你就會通過考試了。
  4. If you had left earlier, you wouldn't have missed the train.
    如果你早點出發，你就不會錯過火車了。
  5. If you had told me about the party, I would have come.
    如果你告訴我派對的事，我就會來了。
  6. If you had worn a coat, you wouldn't have got so cold.
    如果你穿了外套，你就不會那麼冷了。

③ 主詞 + would have + 過去分詞 + if + 主詞 + hadn't + 過去分詞

  1. I went back to look for my friends in the park. I would have stayed there all night if it hadn't closed at six!
    我回公園找我的朋友。如果公園沒有六點關門，我會在那裡待一整晚！
  2. We would have won if our best player hadn't been injured.
    如果我們最好的球員沒有受傷，我們就會贏了。
  3. I would have called you if my phone hadn't died.
    如果我的手機沒有沒電，我就會打給你了。
  4. She would have finished on time if the computer hadn't crashed.
    如果電腦沒有當機，她就會準時完成了。
  5. They would have caught the bus if they hadn't stopped for coffee.
    如果他們沒有停下來喝咖啡，他們就會趕上公車了。
  6. I would have slept well if the neighbours hadn't had a party.
    如果鄰居沒有開派對，我就會睡得很好了。

④ If I had known + 子句, + I would have + 過去分詞

  1. If I had known you were ill, I would have brought you some soup.
    如果我知道你生病了，我就會帶一些湯給你了。
  2. If I had known the shop was closed, I wouldn't have gone into town.
    如果我知道那家店沒開，我就不會進城了。
  3. If we had known about the strike, we would have taken the car.
    如果我們知道有罷工，我們就會開車了。
  4. If she had known the truth, she would have been very angry.
    如果她知道真相，她會很生氣。
  5. If I had known it was your birthday, I would have bought you a present.
    如果我知道今天是你生日，我就會買禮物給你了。
  6. If they had known how cold it was, they would have stayed at home.
    如果他們知道有多冷，他們就會待在家裡了。

⑤ If + 主詞 + hadn't + 過去分詞, + 主詞 + wouldn't have + 過去分詞

  1. If I hadn't missed the bus, I wouldn't have met my best friend.
    如果我沒錯過公車，就不會遇到我最好的朋友了。
  2. If it hadn't rained, the match wouldn't have been cancelled.
    如果沒下雨，比賽就不會取消。（被動）
  3. If she hadn't taken the job, she wouldn't have moved to London.
    如果她沒接受那份工作，她就不會搬到倫敦了。
  4. If we hadn't got lost, we wouldn't have found that lovely beach.
    如果我們沒迷路，就不會發現那個美麗的海灘了。
  5. If my brother hadn't eaten all the prawns, he wouldn't have spent the night in hospital.
    如果我哥哥沒把蝦子全吃掉，他就不會在醫院過夜了。
  6. If you hadn't helped me, I wouldn't have finished the project.
    如果你沒幫我，我就不會完成那個專案了。
  7. If the dog hadn't barked, we wouldn't have woken up.
    如果狗沒有叫，我們就不會醒來了。
