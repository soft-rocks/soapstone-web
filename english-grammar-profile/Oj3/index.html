It would be better if you spent some time in the fresh air with your friends.

你要是能花點時間跟朋友到戶外呼吸新鮮空氣，會比較好。

想⁠像⁠的情⁠況用過⁠去⁠式

It would be better if you spent some time in the fresh air with your friends.

你要是能花點時間跟朋友到戶外呼吸新鮮空氣，會比較好。

if 子⁠句在⁠前或主⁠句在⁠前

It would be better if you spent some time in the fresh air with your friends.

if 在前

If we lived in the city, we wouldn't need a car.

如果我們住在城裡，就不需要車了。
主句在前

It would be easier if we took the train.

我們要是搭火車會比較輕鬆。

勸⁠告用 If I were you

It would be better if you spent some time in the fresh air with your friends.

我要是你，就會跟她道歉。

It would be better if you spent some time in the fresh air with your friends.

If I had more money, I would travel.

It would be better if you spent some time in the fresh air with your friends.

It would be better if you spent some time in the fresh air with your friends.

If I had more time, I would learn Spanish.

例句

① If + 過去簡單式, 主詞 + would

  1. If I spoke Japanese, I would move to Tokyo.
    如果我會說日文，我就會搬去東京。
  2. If we lived in the city, we wouldn't need a car.
    如果我們住在城裡，就不需要車了。
  3. If she knew the truth, she would be furious.
    她要是知道真相，一定會氣炸。
  4. If you asked him nicely, he would probably help.
    你要是好好拜託他，他大概會幫忙。

② 主句在前面

  1. I would buy a bigger flat if I could afford it.
    我要是買得起，就會買大一點的公寓。
  2. It would be easier if we took the train.
    我們要是搭火車會比較輕鬆。
  3. You'd feel much better if you got more sleep.
    你要是多睡一點，會覺得好很多。
  4. They'd be happier if they spent less time on their phones.
    他們少花點時間在手機上會比較快樂。

③ if 子句用 were / was

  1. If the flat were more spacious, we would stay.
    公寓要是寬敞一點，我們就會繼續住。
  2. If it was warmer, we'd eat outside.
    天氣要是暖一點，我們就會在外面吃。
  3. If my brother were taller, he'd play basketball.
    我弟要是高一點，就會去打籃球。

④ If I were you

  1. If I were you, I'd apologise to her.
    我要是你，就會跟她道歉。
  2. I wouldn't sign the contract if I were you.
    換作是我，我不會簽那份合約。
  3. If I were you, I'd see a doctor about that cough.
    我要是你，就會去看醫生，看看那個咳嗽。

⑤ 主句用 could / might

  1. If you wanted to, we could go fishing on Sunday.
    你要是想去，我們星期天可以去釣魚。
  2. If we left now, we might catch the earlier train.
    我們要是現在出發，也許趕得上早一班火車。
  3. If he practised more, he might win next time.
    他要是多練習，下次也許會贏。
  4. If you lent me your bike, I could get there faster.
    你要是借我腳踏車，我就可以快一點到。

⑥ 問句

  1. What would you do if you won the lottery?
    你要是中了樂透，會做什麼？
  2. Where would you live if you could choose?
    如果能選，你會住在哪裡？
  3. Would you go if they offered you the job?
    他們要是給你那份工作，你會去嗎？
  4. How would you feel if your best friend lied to you?
    你最好的朋友要是騙你，你會有什麼感覺？

⑦ It would be better / cheaper if

  1. It would be better if you went to bed earlier.
    你要是早點睡會比較好。
  2. It would be cheaper if we booked the tickets online.
    我們要是在網路上訂票會比較便宜。
  3. It would be quicker if we split the work.
    我們要是分工會比較快。

⑧ if 子句用否定

  1. If I didn't have to work tomorrow, I'd come to the party.
    我明天要是不用上班，就會來派對。
  2. If I didn't live so far away, I'd visit you every week.
    我要是沒住那麼遠，就會每個禮拜去看你。
  3. If she weren't so busy, she'd join the choir.
    她要是沒那麼忙，就會參加合唱團。
  4. We wouldn't be late so often if the buses weren't so unreliable.
    公車要是沒那麼不準時，我們就不會這麼常遲到了。
  5. If people didn't drive so fast, there would be fewer accidents.
    大家要是開車不那麼快，車禍就會少一點。
