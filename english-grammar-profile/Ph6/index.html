You should wear clothes which can get dirty.

你應該穿弄髒也沒關係的衣服。

which 說⁠明是哪⁠一⁠種東⁠西，前⁠面不⁠加逗⁠號

You should wear clothes which can get dirty.

我想要一支拍照好看的手機。

限⁠定關⁠係子⁠句⁠裡，which 和 that 都⁠可⁠以

You should wear clothes which can get dirty.

which

The bus which goes to the airport leaves at six.

開往機場的公車六點開。
that

The bus that goes to the airport leaves at six.

開往機場的公車六點開。

which 就⁠是主⁠詞，不⁠再⁠加 it

You should wear clothes which can get dirty.

I bought a T-shirt which it has a car on it.

I bought a T-shirt which has a car on it.

說⁠明是哪⁠一⁠個，不⁠加逗⁠號

You should wear clothes which can get dirty.

The shoes, which are on the left, are mine.

The shoes which are on the left are mine.

指東⁠西用 which 或 that

You should wear clothes which can get dirty.

I need a bag who is big enough for my laptop.

I need a bag which is big enough for my laptop.

例句

① a / an + 東西 + which ...

  1. I want a phone which takes good photos.
    我想要一支拍照好看的手機。
  2. I bought a T-shirt which has a car on the front.
    我買了一件正面有汽車圖案的 T 恤。
  3. We need a table which seats eight people.
    我們需要一張可以坐八個人的桌子。
  4. She sang a song which made me cry.
    她唱了一首讓我哭的歌。
  5. Do you have a jacket which keeps out the rain?
    你有可以防雨的外套嗎？
  6. I'm looking for a bag which is big enough for my laptop.
    我在找一個大到裝得下筆電的包包。

② 複數 / 不可數名詞 + which ...

  1. Bring shoes which can get wet.
    帶弄濕也沒關係的鞋子。
  2. I like films which make me laugh.
    我喜歡會讓我笑的電影。
  3. They sell vegetables which come from local farms.
    他們賣的蔬菜來自當地的農場。
  4. Buy shoes which are comfortable for walking.
    買走路很舒服的鞋子。
  5. Avoid food which has a lot of sugar.
    避免吃含糖量高的食物。

③ the + 東西 + which ...

  1. The bus which goes to the airport leaves at six.
    開往機場的公車六點開。
  2. The shoes which are on the left are mine.
    左邊那雙鞋是我的。
  3. The road which goes to the beach is closed.
    通往海邊的那條路封閉了。
  4. Where's the book which was on my desk?
    本來在我桌上的那本書在哪裡？
  5. The train which arrives at ten is always late.
    十點到的那班火車總是誤點。

④ that 代替 which

  1. I want a car that uses less petrol.
    我想要一輛比較省油的車。
  2. This is the key that opens the back door.
    這是開後門的鑰匙。
  3. Is there a bus that stops near the museum?
    有停在博物館附近的公車嗎？
  4. They have a dog that barks all night.
    他們養了一隻整晚都在叫的狗。
  5. I need an app that tells me the train times.
    我需要一個會告訴我火車時刻的 app。

⑤ 不同的時態和句型

  1. The storm which hit the town last night broke many windows.
    昨晚襲擊小鎮的暴風雨打破了很多窗戶。
  2. It's a machine which makes coffee and tea.
    那是一台可以煮咖啡和泡茶的機器。
  3. The plants which grow in the shade need less water.
    長在陰涼處的植物需要比較少的水。
  4. Is this the bus which goes to the zoo?
    這是去動物園的公車嗎？
  5. The house which stood here was very old.
    以前在這裡的那棟房子很老。
  6. A song which always makes me smile is on the radio.
    收音機正在播一首總是讓我微笑的歌。
  7. The shop which sold cheap books has closed.
    那家賣便宜書的店關了。
  8. Food which is fresh tastes better.
    新鮮的食物比較好吃。
  9. The email which arrived this morning was from my boss.
    今天早上收到的那封電子郵件是我老闆寄的。
