We have a new employee whose name is Mary Watts.

我們有一位新員工，名字叫 Mary Watts。

whose name 說前⁠面那⁠個⁠人⁠的名⁠字

我們有一位新員工，名字叫 Mary Watts。

說⁠明是哪⁠一個⁠人不⁠加逗⁠號，補⁠充資⁠料加逗⁠號

We have a new employee whose name is Mary Watts.

限定

I met a woman whose name was also Emily.

我認識了一個也叫 Emily 的女人。
非限定

Let me introduce my roommate, whose name is Nikos.

我來介紹我的室友，他叫 Nikos。

whose name 可⁠以當子⁠句⁠的主⁠詞或受⁠詞

We have a new employee whose name is Mary Watts.

主詞

an employee whose name is Mary Watts

受詞

There was a teacher whose name everyone knew.

有一位每個人都知道名字的老師。

說誰⁠的名⁠字用 whose，不⁠用 who's

We have a new employee whose name is Mary Watts.

I have a friend who's name is Lisa.

I have a friend whose name is Lisa.

who's 是 who is。

whose 已⁠經表⁠示他⁠的，不⁠再⁠加 his

We have a new employee whose name is Mary Watts.

I met a man who his name was Carlos.

I met a man whose name was Carlos.

whose name 當受⁠詞⁠時，句⁠尾不⁠再⁠加 it

There's a singer whose name I always forget it.

There's a singer whose name I always forget.

例句

① 限定：whose name + is / was

  1. There's a girl in my class whose name is exactly the same as mine.
    我們班有一個女生跟我同名同姓。
  2. She has a cat whose name is Mr. Whiskers.
    她養了一隻名叫鬍子先生的貓。
  3. They hired a designer whose name was on every magazine cover that year.
    他們請了一位設計師，他的名字那一年出現在每一本雜誌封面上。
  4. I'm reading a book by a writer whose name is hard to pronounce.
    我在看一本書，作者的名字很難唸。
  5. We stayed in a village whose name means "white river."
    我們住在一個名字意思是白色的河的村子。
  6. There's a restaurant on the corner whose name I really like.
    轉角有一家餐廳，我很喜歡它的名字。

② 非限定：, whose name ...

  1. My grandfather, whose name was Henry, was a fisherman.
    我爺爺叫 Henry，他是漁夫。
  2. I spoke to the manager, whose name is Paul Ross.
    我跟經理談過了，他叫 Paul Ross。
  3. Our new puppy, whose name is Biscuit, chews everything.
    我們的新小狗叫餅乾，什麼都咬。
  4. We met her husband, whose name I've already forgotten.
    我們見過她先生，他的名字我已經忘了。
  5. Our dentist, whose name is on the door, is very gentle.
    我們的牙醫很溫柔，他的名字就寫在門上。
  6. The hotel, whose name I didn't catch, was right next to the beach.
    那家飯店就在海灘旁邊，我沒聽清楚它的名字。

③ whose name 當受詞

  1. There was a man at the party whose name nobody knew.
    派對上有一個沒人知道名字的男人。
  2. She's an actress whose name I can never spell.
    她是一個我總是拼不出名字的女演員。
  3. I bought a wine whose name I couldn't pronounce.
    我買了一瓶我唸不出名字的酒。
  4. He's a player whose name every football fan recognizes.
    他是一位每個足球迷都認得名字的球員。
  5. That's the band whose name we saw on the poster.
    那就是我們在海報上看到名字的那個樂團。

④ whose name 後面接其他動詞

  1. The company whose name sounded familiar turned out to be a scam.
    那家名字聽起來很耳熟的公司結果是詐騙。
  2. The man whose name appears on the cheque must sign it.
    支票上寫的那個人要在支票上簽名。
  3. I called the student whose name came first on the list.
    我叫了名單上排第一個的學生。
  4. They're looking for the owner whose name is written inside the bag.
    他們在找名字寫在包包裡面的那個主人。
  5. She's the scientist whose name is going to be on the new building.
    她就是那位名字會放在新大樓上的科學家。

⑤ 不同的情境

  1. Do you know anyone whose name starts with Z?
    你認識名字是 Z 開頭的人嗎？
  2. There's a street in Paris whose name changed five times.
    巴黎有一條街，名字改了五次。
  3. I have a cousin whose name is the same as a famous singer's.
    我有一個表哥跟一位知名歌手同名。
  4. Anyone whose name isn't on the list can't come in.
    名字不在名單上的人不能進來。
  5. Our neighbor, whose name is Mrs. Yang, cleans the park every morning.
    我們的鄰居楊太太每天早上都去打掃公園。
  6. The guide, whose name was Ahmed, spoke five languages.
    導遊叫 Ahmed，他會說五種語言。
  7. Is there someone here whose name is Kim?
    這裡有叫 Kim 的人嗎？
  8. I finally found the song whose name I'd been trying to remember for weeks.
    我終於找到那首歌了，我想它的名字想了好幾個禮拜。
