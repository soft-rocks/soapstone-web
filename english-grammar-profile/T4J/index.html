If you went on holiday with your friends, where would you go?

如果你跟朋友去度假，你會去哪裡？

想⁠像⁠的情⁠況和想⁠像⁠的結⁠果

If you went on holiday with your friends, where would you go?

如果我在路上撿到錢包，我會把它交給警察。

found 不說過去的事。它說想像的情況。

疑⁠問⁠句⁠的 would 放⁠在主⁠詞前⁠面

If you went on holiday with your friends, where would you go?

直述句

If we lived in the city, we would go to the theatre more.

如果我們住在城市，我們會比較常去看戲。
疑問句

If you had a free day tomorrow, what would you do?

如果你明天有一天空閒，你會做什麼？

if 子⁠句放⁠在⁠後⁠面給建⁠議

前面不加逗號

It would be cheaper if you took the bus.

如果你搭公車，會比較便宜。

否⁠定用 didn't 和 wouldn't

didn't
wouldn't

If you didn't stay up so late, you wouldn't feel tired all day.

如果你沒那麼晚睡，就不會整天覺得累。

原句：想⁠像跟朋⁠友去度⁠假

If you went on holiday with your friends, where would you go?

如果你跟朋友去度假，你會去哪裡？

主⁠要⁠子⁠句用 would

If you went on holiday with your friends, where would you go?

If you moved to the coast, you will love it.

If you moved to the coast, you would love it.

if 子⁠句用過⁠去簡⁠單式

If you went on holiday with your friends, where would you go?

If I would have a boat, I would sail around the island.

If I had a boat, I would sail around the island.

疑⁠問⁠句⁠的 would 在主⁠詞前⁠面

If you went on holiday with your friends, where would you go?

If you had a million pounds, what you would buy?

If you had a million pounds, what would you buy?

第⁠一條⁠件⁠句覺⁠得有⁠可⁠能

第一條件句
有可能

If I get the job, I'll move to Leeds.

如果我得到那份工作，我會搬去里茲。
第二條件句
不太可能

If I got a job in London, I'd rent a small flat there.

要是我在倫敦找到工作，我會在那裡租一間小公寓。

第⁠三條⁠件⁠句說過⁠去

第二條件句
現在或未來

If I knew the answer, I would tell you.

如果我知道答案，我會告訴你。
第三條件句
過去

If I had known the answer, I would have told you.

如果我當時知道答案，我就會告訴你了。

例句

① 想像的情況

  1. If I had wings, I would fly over the mountains.
    如果我有翅膀，我會飛越群山。
  2. If my sister lived nearer, I would see her every weekend.
    如果我姊姊住近一點，我每個週末都會去看她。
  3. If we owned a boat, we would spend the summer at sea.
    如果我們有一艘船，就會在海上度過夏天。
  4. If I knew how to sew, I would make my own clothes.
    如果我會縫紉，我會自己做衣服。
  5. If the weekend lasted three days, people would be much happier.
    如果週末有三天，大家會快樂得多。
  6. If he practised every day, he would get better at chess.
    如果他每天練習，他的西洋棋會進步。
  7. If our school had a pool, I would swim every morning.
    如果我們學校有游泳池，我每天早上都會去游泳。

② 問對方的想法

  1. If you won a free trip, where would you go?
    如果你贏得一趟免費旅行，你會去哪裡？
  2. If you met the president, what would you say?
    如果你見到總統，你會說什麼？
  3. If you lost your phone, what would you do first?
    如果你弄丟手機，你第一件事會做什麼？
  4. If your boss offered you a job abroad, would you take it?
    如果你老闆給你一份國外的工作，你會接受嗎？
  5. If you didn't have to work, how would you spend your days?
    如果你不用工作，你會怎麼過日子？
  6. If you had to choose one food forever, which one would it be?
    如果你一輩子只能吃一種食物，你會選哪一種？
  7. If a friend asked you for money, would you lend it?
    如果朋友跟你借錢，你會借嗎？

③ 給建議

  1. Your room would look bigger if you painted the walls white.
    如果你把牆刷成白色，房間看起來會比較大。
  2. If you went to bed earlier, you would feel less tired.
    如果你早點睡，就不會那麼累。
  3. The trip would be cheaper if you booked it in advance.
    如果你提早訂，這趟旅行會比較便宜。
  4. If you spoke to her directly, she would understand.
    如果你直接跟她說，她會理解的。
  5. You would save money if you cooked at home.
    如果你在家煮飯，就會省錢。
  6. If you took a map, you would find the lake easily.
    如果你帶張地圖，就會很容易找到那座湖。
  7. If you asked the teacher, she would explain it again.
    如果你去問老師，她會再解釋一次。

④ didn't 和 wouldn't

  1. If I didn't have a car, I would cycle everywhere.
    如果我沒有車，我會到哪都騎腳踏車。
  2. If the shop wasn't so far away, we would go there more often.
    如果那家店沒那麼遠，我們會比較常去。
  3. If he didn't talk so fast, people would understand him better.
    如果他講話沒那麼快，大家會比較聽得懂。
  4. If it wasn't so expensive, I would buy the leather jacket.
    如果沒那麼貴，我會買那件皮夾克。
  5. I wouldn't go out in this weather if I didn't have to.
    如果不是非出門不可，我不會在這種天氣出去。
  6. We wouldn't need a bigger flat if we didn't have so many books.
    如果我們的書沒那麼多，就不需要大一點的公寓。

⑤ would like to

  1. If I moved, I would like to live near the coast.
    如果我搬家，我想住在海邊附近。
  2. If I had a choice, I would like to work from home.
    如果我可以選，我想在家工作。
  3. If we had more time, we would like to visit the old town.
    如果我們有更多時間，我們想去參觀舊城區。
  4. If I went back to university, I'd like to study history.
    如果我回大學讀書，我想讀歷史。
  5. If she earned more, she'd like to buy a flat of her own.
    如果她賺得多一點，她想買一間自己的公寓。
