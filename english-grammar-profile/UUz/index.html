If you should change your mind and prefer to take a taxi, you can call this number.

萬一出了什麼事，就打當地的緊急電話 112。

If + 主⁠詞 + should + 原⁠形⁠動⁠詞, + 句⁠子

If you should change your mind and prefer to take a taxi, you can call this number.

if … should萬一、如果真的。說不太可能、可是有可能的情況。
原形動詞可能發生的事。
後面的句子常是祈使句或 you can。

緊⁠急情⁠況⁠的指⁠示

例句

If something should happen, call 112.

萬一發生什麼事，打 112。

說緊急情況的指示常用 If something should happen。

should 後⁠面⁠接原⁠形⁠動⁠詞

If you should change your mind and prefer to take a taxi, you can call this number.

If you should changed your mind, call me.

If you should change your mind, call me.

should 後⁠面直⁠接接原⁠形⁠動⁠詞

If you should change your mind and prefer to take a taxi, you can call this number.

If anything should to go wrong, call us.

If anything should go wrong, call us.

should 後⁠面⁠的動⁠詞不⁠變⁠化，一⁠律用原⁠形

If you should change your mind and prefer to take a taxi, you can call this number.

If the train should arrives late, wait here.

If the train should arrive late, wait here.

例句

① If you should + 原形動詞, + 祈使句：給客人和顧客的資訊

  1. Our shuttle bus is free. If you should change your mind and prefer to take a taxi, you can call 3570 outside the airport.
    我們的接駁車是免費的。萬一您改變主意，比較想搭計程車，可以在機場外打 3570。
  2. If you should need anything during the night, please call reception.
    萬一您夜裡需要任何東西，請打電話給櫃台。
  3. If you should lose your key, ask at the front desk.
    萬一您弄丟了鑰匙，請到前台詢問。
  4. If you should have any questions, please write to me.
    萬一您有任何問題，請寫信給我。
  5. If you should arrive after ten, the side door will be open.
    萬一您十點以後到，側門會開著。
  6. If you should feel unwell on the tour, tell the guide immediately.
    萬一您在旅途中覺得不舒服，請馬上告訴導遊。

② If something / anything should happen, + 祈使句：緊急情況

  1. You'll be alone in the house this weekend. If something should happen, call 112, the local emergency number.
    這個週末你會一個人在家。萬一發生什麼事，打 112，這是當地的緊急電話。
  2. If anything should go wrong with the car, phone this garage.
    萬一車子出了什麼問題，打電話給這家修車廠。
  3. If something should happen to me, my sister will look after the dog.
    萬一我出了什麼事，我妹妹會照顧那隻狗。
  4. If anything should break, please tell us before you leave.
    萬一有什麼東西壞了，請在離開前告訴我們。
  5. If something should go wrong during the exam, raise your hand.
    萬一考試時出了什麼問題，請舉手。
  6. If anything should happen to the baby, call the doctor at once.
    萬一寶寶有什麼狀況，馬上打電話給醫生。

③ If + 主詞 + should + 原形動詞, + 主詞 + can / will：可能的安排

  1. If the weather should turn bad, we can move the party indoors.
    萬一天氣變壞，我們可以把派對移到室內。
  2. If the train should be late, I'll wait for you at the café.
    萬一火車誤點，我會在咖啡館等你。
  3. If the shop should close early, we'll go to the market instead.
    萬一那家店提早關門，我們就改去市場。
  4. If the tickets should sell out, we can watch it online.
    萬一票賣完了，我們可以在網路上看。
  5. If my flight should be cancelled, I'll take the train.
    萬一我的班機取消，我會搭火車。（被動）
  6. If the speaker should be ill, Mr Lee will give the talk.
    萬一講者生病，李先生會代替他演講。

④ If you should see / meet + 人, + 祈使句：請對方轉告

  1. If you should see Anna at the party, please give her this card.
    萬一你在派對上見到安娜，請把這張卡片給她。
  2. If you should meet my brother in London, say hello from me.
    萬一你在倫敦遇到我哥哥，幫我跟他打聲招呼。
  3. If you should hear from Tom, ask him to call me.
    萬一你有湯姆的消息，請他打給我。
  4. If you should find my glasses, put them on my desk.
    萬一你找到我的眼鏡，把它們放在我桌上。
  5. If you should pass the bakery, could you buy some bread?
    萬一你經過麵包店，可以買一些麵包嗎？
  6. If you should speak to the manager, mention my complaint.
    萬一你跟經理說話，提一下我的投訴。

⑤ If + 主詞 + should + 原形動詞, + 主詞 + will：正式的承諾

  1. If the goods should arrive damaged, we will replace them free of charge.
    萬一貨物到的時候有損壞，我們會免費更換。
  2. If you should be unhappy with the course, we will give you your money back.
    萬一您對課程不滿意，我們會退錢給您。
  3. If the price should go down, we will refund the difference.
    萬一價格下降，我們會退還差額。
  4. If the hotel should be full, we will find you another one nearby.
    萬一飯店客滿，我們會幫您在附近找另一家。
  5. If the event should be cancelled, all tickets will be refunded.
    萬一活動取消，所有的票都會退款。（被動）
  6. If your parcel should get lost, we will send another one.
    萬一您的包裹遺失，我們會再寄一個。
  7. If the machine should stop working, our engineer will come within a day.
    萬一機器停止運作，我們的工程師會在一天內到。
