If you should get lost, don't hesitate to call us.

萬一迷路了，請儘管打電話給我們。

if + 主⁠詞 + should，說不⁠預⁠期發⁠生⁠的事

If you should get lost, don't hesitate to call us.

如果您使用這套軟體遇到任何問題，請寄電子郵件給我們的支援團隊。

這個句型用在客氣或正式的場合。

主⁠要⁠子⁠句用祈⁠使⁠句

If you should get lost, don't hesitate to call us.

祈使句

If you should miss the last bus, take a taxi and keep the receipt.

如果您錯過末班公車，請搭計程車，並留著收據。
祈使句

If you should feel dizzy, sit down and drink some water.

如果您覺得頭暈，請坐下來喝點水。

主⁠要⁠子⁠句用 will、can 或 would

will
會發生的事

If anyone should ask, I will be in the library.

如果有人問起，我會在圖書館。
can
可以做的事

If the boss should call, I can deal with it.

如果老闆打電話來，我可以處理。
would
可能的結果

If you should decide to sell the car, I would be interested.

如果您決定賣掉那輛車，我會有興趣。

否⁠定：not 放⁠在 should 後⁠面

should not

If the parcel should not arrive, let us know.

如果包裹沒有寄到，請告訴我們。
should not

If the plan should not work, we will try another one.

如果這個計畫行不通，我們會試另一個。

條⁠件子⁠句放⁠在⁠後⁠面，前⁠面不⁠加逗⁠號

主要子句後面

Please call me if you should miss your train.

如果您錯過火車，請打電話給我。
主要子句後面

Please let me know if you should change your plans.

如果您改變計畫，請告訴我。

原句：迷⁠路不⁠一⁠定⁠會發⁠生

If you should get lost, don't hesitate to call us.

萬一迷路了，請儘管打電話給我們。

don't hesitate to call us 請對方儘管打電話。

should 後⁠面不⁠加 to

If you should get lost, don't hesitate to call us.

If you should to need a doctor, call reception.

If you should need a doctor, call reception.

should 和 will 不⁠連⁠用

If you should get lost, don't hesitate to call us.

If you should will arrive early, wait in the lobby.

If you should arrive early, wait in the lobby.

If 的句⁠型把 should 放⁠在主⁠詞後⁠面

If you should get lost, don't hesitate to call us.

If should you have any problems, call this number.

If you should have any problems, call this number.

倒裝時才把 should 放到主詞前面，而且省略 if。

Should 的倒⁠裝意⁠思一⁠樣，只⁠用在書⁠面

Should + 主詞

Should you require a wheelchair, ask a member of staff.

如果您需要輪椅，請詢問工作人員。
Should + 主詞

Should the meeting be cancelled, the secretary will email everyone.

如果會議取消，祕書會寄電子郵件通知大家。

If + 現⁠在簡⁠單式說可⁠能發⁠生⁠的事

If + 現在簡單式

If you get lost, call us.

如果你迷路了，就打給我們。
If + 現在簡單式

If the alarm rings, everyone leaves the building.

如果警報響了，所有人都要離開大樓。

加 should 表示說話的人不預期那件事發生。

例句

① 祈使句

  1. If you should have any questions about the course, please email me.
    如果您對課程有任何問題，請寄電子郵件給我。
  2. If you should see my brother at the party, give him this book.
    如果你在派對上碰到我哥哥，把這本書給他。
  3. If you should find a wallet on the train, hand it to the conductor.
    如果您在火車上撿到錢包，請交給列車長。
  4. If the children should wake up, give them some milk.
    如果孩子醒了，給他們喝點牛奶。
  5. If you should feel dizzy, sit down and drink some water.
    如果您覺得頭暈，請坐下來喝點水。
  6. If you should be in Seoul next month, do come and visit us.
    如果您下個月在首爾，一定要來看我們。
  7. If you should have any concerns about the plan, please tell me.
    如果您對這個計畫有任何疑慮，請告訴我。

② will、can 和 would

  1. If the shop should close early, we can buy bread at the market.
    如果那家店提早關門，我們可以去市場買麵包。
  2. If you should have any problems, the staff at the information desk will help you.
    如果您遇到任何問題，服務台的人員會幫您。
  3. If the weather should change, we will move the party indoors.
    如果天氣變了，我們會把派對移到室內。
  4. If you should decide to sell the car, I would be interested.
    如果您決定賣掉那輛車，我會有興趣。
  5. If the boss should call, I can deal with it.
    如果老闆打電話來，我可以處理。
  6. If you should need a translator, my sister can help.
    如果您需要翻譯，我妹妹可以幫忙。

③ 否定

  1. If the goods should not arrive by Friday, please let us know.
    如果貨星期五前沒到，請告訴我們。
  2. If you should not find the address, ring this number.
    如果您找不到地址，請打這個號碼。
  3. If the plan should not work, we will try another one.
    如果這個計畫行不通，我們會試另一個。
  4. If the key should not fit, ask the caretaker for another.
    如果鑰匙打不開，請跟管理員要另一把。

④ 條件子句放在後面

  1. Don't hesitate to call us if you should need anything.
    如果您需要任何東西，儘管打電話給我們。
  2. Please let me know if you should change your plans.
    如果您改變計畫，請告訴我。
  3. I'll be at home all day if you should want to visit.
    如果你想來玩，我整天都在家。
  4. The guide will meet you at the gate if you should arrive late.
    如果您晚到，導遊會在門口接您。
  5. Ask the nurse for a blanket if you should feel cold.
    如果您覺得冷，請跟護理師要一條毯子。

⑤ 旅遊和服務

  1. If you should miss your connection, the airline will put you on the next flight.
    如果您錯過轉機，航空公司會幫您安排下一班。
  2. If you should lose your passport, go to the embassy.
    如果您弄丟護照，請到大使館。
  3. If you should get lost in the old town, follow the signs to the cathedral.
    如果您在老城區迷路，就跟著往大教堂的指標走。
  4. If your room should be too noisy, the hotel will move you.
    如果您的房間太吵，飯店會幫您換房。
  5. If you should fall ill during the trip, our insurance covers the cost.
    如果您在旅途中生病，我們的保險會支付費用。

⑥ 正式信件和通知

  1. If you should discover any peculation in the accounts, report it to the auditor.
    如果您在帳目中發現挪用公款的情形，請向稽核人員報告。
  2. If you should require a parking permit, the office will issue one.
    如果您需要停車證，辦公室會發一張給您。
  3. If any member should wish to resign, they must write to the secretary.
    如果有會員想退出，必須寫信給祕書。
  4. If you should find the main entrance locked, use the side door.
    如果您發現正門鎖著，請走側門。
  5. If the applicant should fail the interview, we will return the documents.
    如果申請人沒通過面試，我們會退回文件。
