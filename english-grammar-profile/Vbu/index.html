If I were you

It's your decision, but if I had the chance, I would go with my friends.

例句

If I were you, I would not watch TV all the time.

如果我是你，我不會一直看電視。

給建議的時候常用 If I were you。I 後面用 were。

if 子⁠句用過⁠去⁠式

It's your decision, but if I had the chance, I would go with my friends.

If I would have money, I would buy it.

If I had money, I would buy it.

would 後⁠面⁠接原⁠形⁠動⁠詞

It's your decision, but if I had the chance, I would go with my friends.

If I were you, I would went home.

If I were you, I would go home.

would 後⁠面直⁠接接原⁠形⁠動⁠詞

It's your decision, but if I had the chance, I would go with my friends.

If she had time, she would to help us.

If she had time, she would help us.

例句

① If I had + 名詞, I would + 原形動詞：說自己會怎麼做

  1. Your friends have invited you to the beach. It's your decision, but if I had the chance, I would go with my friends.
    你的朋友邀你去海邊。這是你的決定，可是如果我有這個機會，我會跟朋友去。
  2. If I had more time, I would learn to play the piano.
    如果我有更多時間，我會學彈鋼琴。
  3. If I had a garden, I would grow my own vegetables.
    如果我有一座花園，我會自己種蔬菜。
  4. If I had a lot of money, I would travel around the world.
    如果我有很多錢，我會環遊世界。
  5. If I had a dog, I would take it for long walks every day.
    如果我有一隻狗，我每天都會帶牠去散步很久。
  6. If I had a car, I would visit my grandparents more often.
    如果我有車，我會更常去看我的祖父母。

② If I were you, I would (not) + 原形動詞：給建議

  1. You watch TV for six hours a day. If I were you, I would not watch TV all the time.
    你一天看六個小時電視。如果我是你，我不會一直看電視。
  2. If I were you, I would talk to your teacher about it.
    如果我是你，我會跟你的老師談這件事。
  3. If I were you, I would take the job in London.
    如果我是你，我會接受倫敦的那份工作。
  4. If I were you, I wouldn't buy such an expensive phone.
    如果我是你，我不會買那麼貴的手機。
  5. If I were you, I would go to bed early tonight.
    如果我是你，我今天晚上會早點睡。
  6. If I were you, I wouldn't tell anyone about it yet.
    如果我是你，我還不會告訴任何人。

③ If you + 過去式, you would + 原形動詞：說對方可能的結果

  1. If you decided to go to the small country school, you'd probably get more attention as a student.
    如果你決定去那所鄉下的小學校，你當學生可能會得到比較多的照顧。
  2. If you studied a bit every day, you would pass easily.
    如果你每天讀一點書，你會很輕鬆就考過。
  3. If you got up earlier, you wouldn't be late every morning.
    如果你早一點起床，你每天早上就不會遲到。
  4. If you moved closer to work, you would save a lot of time.
    如果你搬到離公司近一點的地方，你會省很多時間。
  5. If you ate more vegetables, you would feel better.
    如果你多吃蔬菜，你會覺得好一點。
  6. If you joined the club, you would meet lots of new people.
    如果你加入那個社團，你會認識很多新朋友。

④ If I were able to + 原形動詞, I wouldn't + 原形動詞：說自己的意見

  1. People ask if I want to move. If I were able to move, I wouldn't, because I think this street is perfect.
    大家問我想不想搬家。就算我能搬，我也不會搬，因為我覺得這條街很完美。
  2. If I were able to choose, I would live by the sea.
    如果我能選，我會住在海邊。
  3. If I were able to change one thing, I would make school start later.
    如果我能改變一件事，我會讓學校晚一點上課。
  4. If I were able to fly, I would visit every country in the world.
    如果我會飛，我會去世界上每一個國家。
  5. If I were able to speak five languages, I would work as a guide.
    如果我會說五種語言，我會去當導遊。
  6. If I were able to cook like my mum, I would open a restaurant.
    如果我能像我媽媽一樣會煮飯，我會開一家餐廳。

⑤ 主詞 + would + 原形動詞 + if + 主詞 + 過去式：if 子句放在後面

  1. I would help you if I knew the answer.
    如果我知道答案，我會幫你。
  2. She would come to the party if she didn't have to work.
    如果她不用工作，她會來派對。
  3. We would buy that house if it were a bit cheaper.
    如果那間房子便宜一點，我們會買。
  4. They would go on holiday more often if they had more money.
    如果他們有更多錢，他們會更常去度假。
  5. My dad would be happier if he worked fewer hours.
    如果我爸爸工作時間少一點，他會比較快樂。
  6. I would call her if I had her number.
    如果我有她的電話號碼，我會打給她。
  7. The town would be nicer if there were fewer cars.
    如果車子少一點，這個鎮會比較好。
