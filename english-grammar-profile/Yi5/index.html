I'd be able to take walks without even worrying about inhaling polluted air.

我就能出去散步，根本不用擔心會吸到被汙染的空氣。

主⁠詞 + 情⁠態動⁠詞 + be able to + 原⁠形⁠動⁠詞

I'd be able to take walks without even worrying about inhaling polluted air.

情態動詞would、might、may、should、must、will。
be able to能夠。be 用原形。
原形動詞能做的事。

為⁠什⁠麼不⁠說 would can

I'd be able to take walks without even worrying about inhaling polluted air.

例句

You might be able to get a ticket at the door.

你也許可以在門口買到票。

should 後⁠面不⁠能接 can，用 be able to

I'd be able to take walks without even worrying about inhaling polluted air.

We should can finish by June.

We should be able to finish by June.

情⁠態動⁠詞後⁠面⁠接原⁠形 be

I'd be able to take walks without even worrying about inhaling polluted air.

You might is able to help.

You might be able to help.

able 後⁠面要⁠有 to

I'd be able to take walks without even worrying about inhaling polluted air.

I'd be able take walks every day.

I'd be able to take walks every day.

例句

① would / 'd + be able to + 原形動詞：假設的情況

  1. If we had a garden, the kids would be able to play outside.
    如果我們有花園，孩子們就能在外面玩。
  2. If I lived closer to work, I'd be able to cycle every day.
    如果我住得離公司近一點，我就能每天騎腳踏車。
  3. If I had more time, I would be able to learn the piano.
    如果我有更多時間，我就能學鋼琴。
  4. With a bigger kitchen, we'd be able to invite more friends for dinner.
    如果廚房大一點，我們就能請更多朋友來吃晚餐。
  5. If the library opened on Sundays, students would be able to study there.
    如果圖書館星期天開放，學生就能去那裡讀書。
  6. If she spoke English, she'd be able to get a better job.
    如果她會說英文，她就能找到更好的工作。
  7. Without the noise from the road, we'd be able to sleep with the windows open.
    如果沒有馬路上的噪音，我們就能開著窗睡覺。
  8. If you came by train, you'd be able to relax on the way.
    如果你搭火車來，路上就能放鬆一下。

② might / may + be able to + 原形動詞：也許能夠

  1. After finishing school, you might be able to spend more time with your friends.
    畢業以後，你也許能多花點時間跟朋友在一起。
  2. You might be able to get a cheaper flight on Tuesday.
    星期二你也許能買到比較便宜的機票。
  3. I may be able to leave work early on Friday.
    我星期五也許可以早點下班。
  4. The mechanic might be able to fix the car today.
    技師今天也許能修好車。
  5. If we ask nicely, they may be able to give us a better room.
    如果我們客氣地問，他們也許能給我們一間比較好的房間。
  6. Grandpa might be able to come to the concert after all.
    爺爺最後也許能來聽音樂會。
  7. We may be able to see the northern lights tonight.
    我們今晚也許能看到北極光。

③ should + be able to + 原形動詞：應該能夠

  1. If we could meet in Switzerland, we should be able to finish the project by the 20th of June.
    如果我們能在瑞士見面，應該能在六月二十日前完成專案。
  2. With the new software, you should be able to work much faster.
    有了新軟體，你應該能做得快很多。
  3. The bus leaves at six, so we should be able to get home by eight.
    公車六點開，所以我們應該能在八點前到家。
  4. A good student should be able to answer this question.
    好學生應該能回答這個問題。
  5. If you follow the map, you should be able to find the house easily.
    如果你照著地圖走，應該很容易就能找到那間房子。
  6. The new hospital should be able to treat more patients.
    新醫院應該能治療更多病人。
  7. After a year in Paris, you should be able to speak good French.
    在巴黎待一年後，你應該能說一口好法文。

④ must / will + be able to + 原形動詞

  1. All drivers must be able to read a number plate from twenty metres.
    所有駕駛都必須能看清楚二十公尺外的車牌。
  2. Applicants must be able to speak two languages.
    應徵者必須會說兩種語言。
  3. Nurses must be able to work at night.
    護理師必須能上夜班。
  4. Children must be able to swim before they join the sailing club.
    孩子們加入帆船社之前，必須會游泳。
  5. After the operation, you will be able to see clearly again.
    手術後你就能再看清楚了。
  6. Once you get your licence, you'll be able to drive to work.
    等你拿到駕照，你就能開車上班。

⑤ 否定：情態動詞 + not + be able to

  1. Without your help, I wouldn't be able to finish this.
    沒有你的幫忙，我沒辦法完成這件事。
  2. I might not be able to come to the meeting tomorrow.
    我明天也許沒辦法來開會。
  3. If it rains, we may not be able to play the match.
    如果下雨，我們也許沒辦法比賽。
