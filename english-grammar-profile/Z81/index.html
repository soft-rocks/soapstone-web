如果你想找樂子和刺激，我會選城市。

先說對⁠方⁠的計⁠畫，再給建⁠議

If you are looking for fun and excitement, I would go for the city.

如果你要搭火車，應該先訂位。

現⁠在進⁠行⁠式說計⁠畫或正⁠在找⁠的事

If you are looking for fun and excitement, I would go for the city.

計畫

If you're staying in Paris next week, you must visit the market.

如果你下週要待在巴黎，一定要去逛那個市場。
正在找

If you're looking for a quiet hotel, try the one by the river.

如果你在找安靜的飯店，試試河邊那家。

be going to

If you're going to paint the kitchen, buy enough paint first.

如果你打算粉刷廚房，先買夠油漆。

原句：你⁠要刺⁠激，我⁠會選城⁠市

If you are looking for fun and excitement, I would go for the city.

如果你想找樂子和刺激，我會選城市。

go for 的意思是選擇。

if 子⁠句說計⁠畫不⁠用 will

If you are looking for fun and excitement, I would go for the city.

If you will travel abroad, you should get some local money.

If you're travelling abroad, you should get some local money.

現⁠在進⁠行⁠式要⁠有 be 動⁠詞

If you are looking for fun and excitement, I would go for the city.

If you going to the party, wear something warm.

If you're going to the party, wear something warm.

should 後⁠面不⁠加 to

If you are looking for fun and excitement, I would go for the city.

If you are going to move, you should to visit both schools first.

If you are going to move, you should visit both schools first.

現⁠在簡⁠單式說一⁠般⁠的條⁠件

現在簡單式
一般的條件

If you study abroad, you'll learn the language fast.

如果你出國讀書，會很快學會那個語言。
現在進行式
計畫好的事

If you're studying abroad next year, you need to apply for a visa.

如果你明年要出國讀書，就要申請簽證。

現⁠在進⁠行⁠式也說正⁠在發⁠生⁠的事

正在發生

If you're feeling sick, go and lie down.

如果你覺得不舒服，就去躺一下。
計畫

If you're leaving early tomorrow, set an alarm.

如果你明天要早點出門，就設個鬧鐘。

例句

① 計畫好的事

  1. If you're flying to Rome on Friday, you should check in online.
    如果你星期五要飛羅馬，應該先線上報到。
  2. If you're staying with us, you can use the spare room.
    如果你要住我們家，可以用客房。
  3. If you're coming to the wedding, please reply by Monday.
    如果你要來參加婚禮，請在星期一前回覆。
  4. If you're cooking dinner tonight, don't forget the bread.
    如果你今晚要煮晚餐，別忘了麵包。
  5. If they're arriving late, we can leave the key with the neighbour.
    如果他們會晚到，我們可以把鑰匙留給鄰居。
  6. If you're moving house next month, you should tell the bank.
    如果你下個月要搬家，應該通知銀行。
  7. If you're meeting Sam tomorrow, give him this book.
    如果你明天要跟 Sam 見面，把這本書給他。
  8. If you're taking the children to the beach, bring plenty of sun cream.
    如果你要帶孩子去海邊，多帶點防曬乳。

② 正在找或考慮的事

  1. If you're looking for a cheap lunch, the market has great stalls.
    如果你在找便宜的午餐，市場有很棒的攤位。
  2. If you're thinking of learning Italian, I'd start with an evening class.
    如果你在考慮學義大利文，我會從夜間課程開始。
  3. If you're hoping to see the northern lights, go in winter.
    如果你希望看到北極光，就冬天去。
  4. If you're planning a picnic, the park by the lake is lovely.
    如果你在計畫野餐，湖邊的公園很棒。
  5. If you're looking for adventure, you could try rock climbing.
    如果你在找刺激的活動，可以試試攀岩。
  6. If you're considering a new phone, you should wait for the sales.
    如果你在考慮買新手機，應該等特價。
  7. If you're trying to lose weight, you should cut down on sugar.
    如果你想減重，應該少吃糖。

③ If + be going to

  1. If you're going to study abroad, you should start saving now.
    如果你打算出國讀書，現在就應該開始存錢。
  2. If you're going to drive all night, take a break every two hours.
    如果你打算開整晚的車，每兩個小時休息一次。
  3. If we're going to finish on time, we must start now.
    如果我們想準時完成，現在就得開始。
  4. If you're going to buy a dog, think about who will walk it.
    如果你打算買狗，先想想誰要遛牠。
  5. If she's going to run the marathon, she needs to train every day.
    如果她打算跑馬拉松，就得每天訓練。
  6. If you're going to be late, please call me.
    如果你會遲到，請打電話給我。
  7. If you're going to live in a big city, you should choose a flat near the underground.
    如果你打算住在大城市，應該選地鐵站附近的公寓。

④ I'd 或 I would

  1. If you're looking for peace and quiet, I'd choose the village.
    如果你在找寧靜，我會選那個村子。
  2. If you're planning to stay a month, I'd rent a flat instead of a hotel room.
    如果你打算待一個月，我會租公寓，不住飯店。
  3. If you're starting a new job on Monday, I'd get an early night on Sunday.
    如果你星期一要開始新工作，換作是我，星期天會早點睡。
  4. If you're buying a used car, I would take a mechanic with you.
    如果你要買二手車，我會帶個技師一起去。
  5. If you're visiting Scotland, I'd take a waterproof jacket.
    如果你要去蘇格蘭，我會帶一件防水外套。

⑤ 祈使句

  1. If you're travelling with friends, choose them carefully.
    如果你要和朋友去旅行，要小心挑選旅伴。
  2. If you're applying for that job, ask your teacher for a reference.
    如果你要應徵那份工作，請老師幫你寫推薦信。
  3. If you're having a party, remember to tell the neighbours.
    如果你要辦派對，記得跟鄰居說一聲。
  4. If you're choosing a new school, visit a few of them first.
    如果你在挑新學校，先去幾間看看。
  5. If you're going camping, don't forget a torch.
    如果你要去露營，別忘了帶手電筒。
