Taking everything into account, it can be concluded that the current training course is very useful for our company.

綜合考量各方面，可以得出結論：目前的訓練課程對我們公司非常有用。

It + can be + 過⁠去⁠分⁠詞 + (that) + 子⁠句

Taking everything into account, it can be concluded that the current training course is very useful for our company.

it形式主詞，指後面的 that 子句。
can be + 過去分詞被動語態，表示「可以這樣說、這樣看」。
that 子句作者的看法或結論。

被⁠動⁠語⁠態是 can be 加過⁠去⁠分⁠詞

Taking everything into account, it can be concluded that the current training course is very useful for our company.

It can concluded that the plan works.

It can be concluded that the plan works.

be 後⁠面⁠接過⁠去⁠分⁠詞

Taking everything into account, it can be concluded that the current training course is very useful for our company.

It can be say that prices are too high.

It can be said that prices are too high.

句⁠子要⁠有主⁠詞

Taking everything into account, it can be concluded that the current training course is very useful for our company.

Can be argued that the company should change.

It can be argued that the company should change.

例句

① It can be said that + 子句

  1. As for marriage, it can be said that women with a job no longer quit after they get married.
    說到婚姻，可以說有工作的女性結婚後不再辭職了。
  2. It can be said that the internet has changed the way we shop.
    可以說網路改變了我們買東西的方式。
  3. It can be said that the town has become much safer in recent years.
    可以說這幾年這個鎮變得安全多了。
  4. In general, it can be said that the students enjoyed the course.
    整體來說，可以說學生們喜歡這門課。
  5. It can be said that the festival was a great success.
    可以說這次節慶活動非常成功。
  6. It can be said that young people read less than before.
    可以說年輕人讀的書比以前少。

② It can be argued that + 子句

  1. Looking at the figures, it can be argued that the company should leave the heater market.
    從數字來看，可以主張公司應該退出暖氣機市場。
  2. It can be argued that schools should start later in the morning.
    可以主張學校早上應該晚一點上課。
  3. It can be argued that tourism does more harm than good to the island.
    可以主張觀光對這座島的害處大於好處。
  4. It can be argued that the new law is unfair to small shops.
    可以主張新法律對小商店不公平。
  5. It can be argued that television is a useful tool for learning.
    可以主張電視是很有用的學習工具。
  6. On the other hand, it can be argued that the price is too high.
    另一方面，可以主張價格太高了。

③ It can be concluded that + 子句

  1. Taking everything into account, it can be concluded that the move to the new office was the right decision.
    綜合考量各方面，可以得出結論：搬到新辦公室是正確的決定。
  2. From the survey, it can be concluded that most customers are happy with the service.
    從調查可以得出結論：大部分的顧客對服務很滿意。
  3. It can be concluded that the project needs more money.
    可以得出結論：這個專案需要更多經費。
  4. From these results, it can be concluded that the medicine works.
    從這些結果可以得出結論：這種藥有效。
  5. It can be concluded that the old system should be replaced.
    可以得出結論：舊系統應該被取代。
  6. It can be concluded that the new timetable has reduced delays.
    可以得出結論：新的時刻表減少了誤點。

④ It can be seen that + 子句

  1. From the chart, it can be seen that sales rose sharply in March.
    從圖表可以看出，三月的銷售量大幅上升。
  2. It can be seen that more people now work from home.
    可以看出現在有更多人在家工作。
  3. It can be seen from the table that prices fell in the summer.
    從表格可以看出，夏天的價格下降了。
  4. It can be seen that the number of visitors doubled.
    可以看出訪客人數增加了一倍。
  5. It can clearly be seen that the plan has failed.
    可以清楚看出這個計畫失敗了。
  6. From the photos, it can be seen that the building is in poor condition.
    從照片可以看出這棟建築的狀況很差。

⑤ It can be assumed / expected / noted that + 子句

  1. It can be noted that most complaints came from new customers.
    值得一提的是，大部分的投訴來自新顧客。
  2. It can be assumed that most readers know the story.
    可以假定大部分的讀者都知道這個故事。
  3. It can be expected that prices will rise next year.
    可以預期明年價格會上漲。
  4. It can be assumed that the weather will be warm in July.
    可以假定七月的天氣會很溫暖。
  5. It can be expected that more students will apply this year.
    可以預期今年會有更多學生申請。
  6. It can be expected that the roads will be busy over the holiday.
    可以預期假期期間路上會很塞。
  7. It can be noted that the staff worked very hard this year.
    值得一提的是，員工今年非常努力。
