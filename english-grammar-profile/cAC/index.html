I don't usually wear dresses, but I had to buy this one because I am going to be in a singing competition.

我平常不太穿洋裝，可是我得買這件，因為我要參加一場歌唱比賽。

this one 代⁠替單⁠數名⁠詞

I don't usually wear dresses, but I had to buy this one because I am going to be in a singing competition.

我平常不太穿洋裝，可是我得買這件，因為我要參加一場歌唱比賽。

this one 和 that one

I don't usually wear dresses, but I had to buy this one because I am going to be in a singing competition.

近的東西

My phone is old. I want to buy this one.

我的手機很舊了，我想買這支。
遠的東西

Which car is yours? Is it that one over there?

哪一輛車是你的？是那邊那輛嗎？
對方說過的

"You should try the new café." "I've been to that one."

「你應該去試試新開的咖啡店。」「那家我去過了。」

前⁠面⁠的名⁠詞

I don't usually wear dresses, but I had to buy this one because I am going to be in a singing competition.

複數的其中一個

I don't usually eat sweets, but I'll try this one.

我平常不太吃甜食，不過這個我要嚐嚐看。

I like that red one.

我喜歡那個紅色的。

不⁠可⁠數⁠名⁠詞不⁠用 one

I don't usually wear dresses, but I had to buy this one because I am going to be in a singing competition.

I don't like this music. Can we listen to something else?

複⁠數名⁠詞用 those

I don't usually wear dresses, but I had to buy this one because I am going to be in a singing competition.

I need new shoes. I really like those in the window.

one：任⁠何一⁠個

我需要一支筆，可以借我一支嗎？

the one + 說⁠明

哪一件外套是你的？有黑色扣子的那件。

例句

① this one：近的東西

  1. I've tried on lots of jackets, but I like this one best.
    我試穿了很多件夾克，可是我最喜歡這件。
  2. My old bike was stolen, so I bought this one.
    我的舊腳踏車被偷了，所以我買了這輛。
  3. I've read all his books. This one is the funniest.
    他的書我都讀過，這本最好笑。
  4. There are many cafés here, but this one has the best coffee.
    這裡有很多咖啡店，可是這家的咖啡最好喝。
  5. That hotel was noisy, so we moved to this one.
    那家旅館很吵，所以我們搬到這家。

② that one：遠的東西

  1. Which house do you live in? That one with the green door.
    你住哪一棟房子？那棟有綠色大門的。
  2. This table is too small. Let's sit at that one by the window.
    這張桌子太小了，我們去坐窗邊那張吧。
  3. I don't want this cake. Can I have that one?
    我不要這塊蛋糕，我可以吃那塊嗎？
  4. This bus doesn't go to the station. You need to take that one.
    這班公車不到車站，你要搭那班。
  5. Look at all those dogs. That one is really cute.
    你看那些狗，那隻好可愛。

③ 指對方說過的東西

  1. "Did you like the film last night?" "No, I didn't enjoy that one."
    你喜歡昨晚那部電影嗎？不喜歡，那部我看得不開心。
  2. "Have you read the book I gave you?" "Yes, that one was great."
    你讀了我給你的那本書嗎？讀了，那本很棒。
  3. "Do you know the song on the radio?" "Yes, that one is my favourite."
    你知道廣播在放的那首歌嗎？知道，那首是我最喜歡的。
  4. "I'm thinking about the job at the bank." "I think you should take that one."
    我在考慮銀行那份工作。我覺得你應該接那份。
  5. "Is the blue car yours?" "No, mine is that one behind it."
    那輛藍色的車是你的嗎？不是，我的是後面那輛。

④ 在商店

  1. I like these mugs. How much is this one?
    我喜歡這些馬克杯，這個多少錢？
  2. This shirt is too big. Have you got this one in a smaller size?
    這件襯衫太大了，這件有小一點的尺寸嗎？
  3. I'm looking for a watch. Can I see that one, please?
    我在找手錶，可以給我看看那支嗎？
  4. This lamp is too bright. Can I see that one in the corner?
    這盞燈太亮了，我可以看看角落那盞嗎？
  5. All these cakes look good, but I'll take this one.
    這些蛋糕看起來都很好吃，不過我要這塊。

⑤ 中間加形容詞

  1. I don't want the black hat. I'll take that brown one.
    我不要那頂黑帽子，我要那頂咖啡色的。
  2. That old laptop is too slow. I'll use this new one.
    那台舊筆電太慢了，我要用這台新的。
  3. This big room is for meetings, and that small one is my office.
    這間大房間是開會用的，那間小的是我的辦公室。
  4. Which apple do you want, this green one or that red one?
    你要哪一顆蘋果，這顆綠的還是那顆紅的？
  5. I don't want this plastic chair. I'll sit on that wooden one.
    我不要這張塑膠椅，我要坐那張木頭的。

⑥ 選擇和說明原因

  1. There were two films on TV, and I chose this one because it was short.
    電視上有兩部電影，我選了這部，因為它比較短。
  2. Of all the films on the list, I've chosen that one because my father and brother like it too.
    清單上那麼多電影，我選了那部，因為我爸爸和哥哥也喜歡。
  3. There are two English courses. I'm taking this one because it's in the evening.
    有兩門英文課，我要上這門，因為它在晚上上課。
  4. We looked at three flats and decided on that one near the park.
    我們看了三間公寓，決定租公園附近那間。
  5. I usually take the early bus, but today I took this one because I got up late.
    我平常搭早一點的公車，不過今天睡晚了，所以搭了這班。
  6. I don't usually eat spicy dishes, but I ordered this one because it looked so good.
    我平常不太吃辣的菜，不過我點了這道，因為它看起來很好吃。
