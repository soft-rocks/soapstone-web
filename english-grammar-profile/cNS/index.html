例句

① I would

  1. If I were you, I would check the timetable before you leave.
    如果我是你，出門前會先查一下時刻表。
  2. If I were you, I would write everything down.
    如果我是你，我會把所有事情寫下來。
  3. If I were you, I would ask for a second opinion.
    如果我是你，我會再問問別的醫生的意見。
  4. If I were you, I would start revising this week.
    如果我是你，這週就會開始複習。
  5. If I were you, I would take an extra jumper for the evening.
    如果我是你，我會多帶一件毛衣晚上穿。
  6. If I were you, I would change your password.
    如果我是你，我會換掉密碼。
  7. If I were you, I would join a running club.
    如果我是你，我會加入跑步社。
  8. If I were you, I would phone the landlord about the leak.
    如果我是你，我會打電話跟房東說漏水的事。

② I'd

  1. If I were you, I'd speak to the manager.
    如果我是你，我會去找經理談。
  2. If I were you, I'd get there an hour early.
    如果我是你，我會提早一小時到。
  3. If I were you, I'd sell the old car before winter.
    如果我是你，我會在冬天前把舊車賣掉。
  4. If I were you, I'd say sorry first.
    如果我是你，我會先道歉。
  5. If I were you, I'd buy a return ticket.
    如果我是你，我會買來回票。
  6. If I were you, I'd keep a copy of the email.
    如果我是你，我會把那封電子郵件留一份副本。

③ I wouldn't

  1. If I were you, I wouldn't eat the fish here.
    如果我是你，我不會吃這裡的魚。
  2. If I were you, I wouldn't leave your bike outside overnight.
    如果我是你，我不會把腳踏車整晚放在外面。
  3. If I were you, I wouldn't worry about the test.
    如果我是你，我不會擔心那個考試。
  4. If I were you, I wouldn't believe everything he says.
    如果我是你，我不會相信他說的每一句話。
  5. If I were you, I wouldn't drive in this snow.
    如果我是你，我不會在這種大雪裡開車。
  6. If I were you, I wouldn't post that photo online.
    如果我是你，我不會把那張照片貼到網路上。

④ 主要子句 + if I were you

  1. I'd take an umbrella if I were you.
    如果我是你，我會帶把傘。
  2. I'd book a table if I were you.
    如果我是你，我會先訂位。
  3. I would read the instructions again if I were you.
    如果我是你，我會再看一次說明。
  4. I wouldn't park in front of the gate if I were you.
    如果我是你，我不會把車停在大門前面。
  5. I'd turn the music down if I were you.
    如果我是你，我會把音樂關小聲一點。
  6. I wouldn't mention the price to your parents if I were you.
    如果我是你，我不會跟你爸媽提價錢。

⑤ 替對方做選擇

  1. If I were you, I'd choose the cheaper flat near the station.
    如果我是你，我會選車站附近比較便宜的公寓。
  2. If I were you, I would study medicine because you love science.
    如果我是你，我會讀醫學，因為你喜歡科學。
  3. If I were you, I'd go to the beach in June, when it's quieter.
    如果我是你，我會六月去海邊，那時候人比較少。
  4. If I were you, I'd stay with your aunt rather than in a hotel.
    如果我是你，我會住在你阿姨家，不住飯店。
  5. If I were you, I'd pick the red dress for the wedding.
    如果我是你，我會選紅色那件洋裝去參加婚禮。
  6. If I were you, I'd do both and see which one you enjoy more.
    如果我是你，我兩個都會試試，看哪一個比較喜歡。
