I'm going to a concert on Saturday. Would you like to go with me?

Sarah，你今天晚上想打網球嗎？

Would you like + to + 原⁠形⁠動⁠詞？

Would you like to、Would you like + 名⁠詞

Would you like to你想……嗎？邀請對方做某件事。
Would you like + 名詞你想要……嗎？問對方要不要某樣東西。

先說計⁠畫，再邀⁠請

例句

I want to watch the film. Would you like to come with me?

我想去看那部電影。你想跟我一起去嗎？

邀請常先說自己的計畫，再問對方。

would you like 後⁠面⁠接動⁠詞⁠時要加 to

I'm going to a concert on Saturday. Would you like to go with me?

Would you like come with me?

Would you like to come with me?

問⁠句把 would 放⁠在句⁠首，不⁠用 do

I'm going to a concert on Saturday. Would you like to go with me?

Do you would like some tea?

Would you like some tea?

to 後⁠面⁠接原⁠形⁠動⁠詞

I'm going to a concert on Saturday. Would you like to go with me?

Would you like to playing tennis?

Would you like to play tennis?

例句

① Would you like to + 原形動詞 + with me？：邀請一起去

  1. I've got two tickets for a concert on Saturday. Would you like to go with me?
    我有兩張星期六演唱會的票。你想跟我一起去嗎？
  2. I want to watch the new film tonight. Would you like to come with me?
    我今天晚上想看那部新電影。你想跟我一起去嗎？
  3. I'm going to the market on Sunday morning. Would you like to come along?
    我星期天早上要去市場。你想一起來嗎？
  4. I'm taking the dog to the beach. Would you like to join us?
    我要帶狗去海灘。你想跟我們一起去嗎？
  5. My family is going camping next month. Would you like to come with us?
    我們家下個月要去露營。你想跟我們一起去嗎？
  6. I'm going to the new museum on Friday. Would you like to come too?
    我星期五要去新的博物館。你也想一起來嗎？

② 人名, would you like to + 原形動詞？：邀請一起做

  1. Sarah, would you like to play tennis this evening?
    莎拉，你今天傍晚想打網球嗎？
  2. Tom, would you like to come to my house after school?
    湯姆，你放學後想來我家嗎？
  3. Anna, would you like to be in our team for the quiz?
    安娜，你想加入我們這隊參加問答比賽嗎？
  4. Ben, would you like to help me make the cake?
    班，你想幫我做蛋糕嗎？
  5. Lucy, would you like to sit next to me on the bus?
    露西，你想在巴士上坐我旁邊嗎？
  6. Mark, would you like to borrow my bike this weekend?
    馬克，你這個週末想借我的腳踏車嗎？

③ Would you like + 名詞？：問對方要不要

  1. You look cold. Would you like a cup of hot chocolate?
    你看起來很冷。你想要一杯熱可可嗎？
  2. Would you like some more cake? There's plenty left.
    你想再吃一些蛋糕嗎？還剩很多。
  3. Would you like a lift to the station?
    你想要我載你去車站嗎？
  4. Would you like a seat? You've been standing for ages.
    你想坐下嗎？你站好久了。
  5. Would you like some help with your homework?
    你寫功課需要幫忙嗎？
  6. Would you like a glass of water with your medicine?
    你吃藥要配一杯水嗎？

④ Would you like to + 原形動詞？：問對方的意願

  1. Would you like to see the photos from our holiday?
    你想看我們度假的照片嗎？
  2. Would you like to try on the blue dress?
    你想試穿那件藍色洋裝嗎？
  3. Would you like to stay for dinner?
    你想留下來吃晚餐嗎？
  4. Would you like to leave a message for her?
    你想留言給她嗎？
  5. Would you like to sit by the window?
    你想坐在窗邊嗎？
  6. Would you like to hear my new song?
    你想聽我的新歌嗎？

⑤ 疑問詞 + would you like to + 原形動詞？

  1. What would you like to do for your birthday?
    你生日想做什麼？
  2. Where would you like to go on holiday this year?
    你今年想去哪裡度假？
  3. When would you like to meet next week?
    你下星期想什麼時候見面？
  4. The café has twenty kinds of tea. Which one would you like to try?
    這家咖啡館有二十種茶。你想試哪一種？
  5. Which film would you like to see tonight?
    你今天晚上想看哪一部電影？
  6. What would you like to be when you grow up?
    你長大想當什麼？
  7. Who would you like to invite to the party?
    你想邀請誰來派對？
