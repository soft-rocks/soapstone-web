I will come see you on Friday if it's OK with you.

如果你方便的話，我星期五會去看你。

if 子⁠句說⁠出條⁠件，可⁠以放⁠在主⁠要⁠子⁠句後⁠面

如果你方便的話，我星期五會去看你。

if 子⁠句在⁠後⁠面不⁠加逗⁠號，在⁠前⁠面要加逗⁠號

I will come see you on Friday if it's OK with you.

後面

We can go to the beach if the weather is nice.

如果天氣好，我們可以去海邊。
前面

If you're hungry, there's some pizza in the fridge.

如果你餓了，冰箱裡有披薩。

說未⁠來⁠的條⁠件，if 子⁠句用現⁠在⁠式

I will come see you on Friday if it's OK with you.

will

If it rains tomorrow, we'll stay at home.

如果明天下雨，我們就待在家。
祈使句

If you see Mark, say hello from me.

如果你看到 Mark，幫我跟他問好。

說未⁠來⁠的條⁠件，if 子⁠句不⁠用 will

I will come see you on Friday if it's OK with you.

If it will rain, we'll take the bus.

If it rains, we'll take the bus.

if 已⁠經連⁠接兩⁠個子⁠句，不⁠加 so

If you need help, so call me.

If you need help, call me.

if 後⁠面要⁠有主⁠詞

I will come see you on Friday if it's OK with you.

I'll buy it if is cheap.

I'll buy it if it is cheap.

例句

① if 子句放在後面

  1. You can borrow my bike if you need it.
    如果你需要，可以借我的腳踏車。
  2. I'll make some tea if you're staying a bit longer.
    如果你要多待一下，我就泡點茶。
  3. We'll miss the train if we don't leave now.
    如果我們不現在出發，就會趕不上火車。
  4. Call the doctor if your fever gets worse.
    如果你發燒更嚴重，就打給醫生。
  5. My dad gets angry if I come home late.
    如果我晚回家，我爸就會生氣。
  6. I'd love to join you if there's room in the car.
    如果車上還有位子，我很想跟你們一起去。

② if 子句放在前面

  1. If you like spicy food, you'll love this restaurant.
    如果你喜歡吃辣，你一定會愛這家餐廳。
  2. If the shop is closed, try the one across the street.
    如果那家店沒開，就去對面那家看看。
  3. If the printer jams again, unplug it for a minute.
    如果印表機又卡紙，就把插頭拔掉一分鐘。
  4. If I have time this weekend, I'll paint the kitchen.
    如果我這個週末有空，我就來漆廚房。
  5. If the baby wakes up, give her some milk.
    如果寶寶醒了，就餵她喝點奶。
  6. If you're cold, close the window.
    如果你冷，就把窗戶關起來。

③ if 子句 + will / can / 祈使句

  1. If you study every day, you'll pass easily.
    如果你每天念書，就能輕鬆考過。
  2. If we hurry, we can catch the last bus.
    如果我們快一點，就能搭上最後一班公車。
  3. If anyone calls, tell them I'm in a meeting.
    如果有人打來，就說我在開會。
  4. If you heat ice, it melts.
    冰加熱就會融化。
  5. If you're free on Saturday, come to my party.
    如果你星期六有空，就來我的派對。

④ 回應和請求

  1. Let me know if you have any questions.
    如果你有任何問題，跟我說。
  2. Take another cookie if you want.
    如果你想吃，再拿一塊餅乾。
  3. I can help you move if you like.
    如果你需要，我可以幫你搬家。
  4. Sit down if you're tired.
    如果你累了，就坐下來。
  5. Please send me the photos if you remember.
    如果你記得的話，請把照片寄給我。

⑤ 不同的情境

  1. If the meeting finishes early, let's have lunch together.
    如果會議提早結束，我們一起吃午餐吧。
  2. The plants will die if you don't water them.
    如果你不澆水，植物會死掉。
  3. If you specify the size, we can order it for you.
    如果你說明尺寸，我們可以幫你訂。
  4. If you're ever in Kaohsiung, give me a call.
    如果你有來高雄，打給我。
  5. If there's a problem with the room, call reception.
    如果房間有問題，打給櫃台。
  6. You won't get a seat if you arrive after seven.
    如果你七點以後才到，就不會有位子。
  7. If my sister can't come, I'll go on my own.
    如果我姊姊不能來，我就自己去。
  8. The dog barks if someone rings the doorbell.
    如果有人按門鈴，狗就會叫。
