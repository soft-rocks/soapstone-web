I'm sure your parents will be happy if you go with them.

我相信如果你跟你爸媽一起去，他們會很高興。

可⁠能⁠的條⁠件和很⁠可⁠能⁠的結⁠果

I'm sure your parents will be happy if you go with them.

如果我們搭計程車，就會準時到。

if 子⁠句放⁠在⁠前⁠面或後⁠面

I'm sure your parents will be happy if you go with them.

放在前面
後面加逗號

If she sends the form today, she'll get an answer next week.

如果她今天寄出表格，下週就會收到回覆。
放在後面
前面不加逗號

You'll feel better if you get some sleep.

如果你睡一下，就會覺得好一點。

否⁠定用 don't 和 won't

don't
won't

If you don't water the plants, they won't survive the summer.

如果你不幫植物澆水，它們熬不過夏天。

疑⁠問⁠句⁠的 will 放⁠在主⁠詞前⁠面

疑問句

What will you do if the flight is cancelled?

如果班機取消了，你會怎麼辦？

加 I'm sure、I think 或 probably

I'm sure your parents will be happy if you go with them.

I think
沒那麼確定

I think the shop will give you a refund if you show the receipt.

我想如果你出示收據，店家會退錢給你。

probably 也說沒那麼確定。

原句：跟爸媽⁠去，他⁠們會高⁠興

I'm sure your parents will be happy if you go with them.

我相信如果你跟你爸媽一起去，他們會很高興。

if 子⁠句不⁠用 will

I'm sure your parents will be happy if you go with them.

If it will be sunny tomorrow, we'll go to the lake.

If it's sunny tomorrow, we'll go to the lake.

主⁠要⁠子⁠句要⁠用 will

I'm sure your parents will be happy if you go with them.

If the bus is late tomorrow, I miss my meeting.

If the bus is late tomorrow, I'll miss my meeting.

疑⁠問⁠句不⁠用直⁠述⁠句⁠的語⁠序

Where you will stay if your flight is delayed?

Where will you stay if your flight is delayed?

零條⁠件⁠句說每⁠次都成⁠立⁠的事

零條件句
每次都成立

If you heat water to 100 degrees, it boils.

如果把水加熱到一百度，水就會沸騰。
第一條件句
未來某一次

If you leave the ice cream in the sun, it will melt.

如果你把冰淇淋放在太陽下，它會融化。

when 說確⁠定會發⁠生⁠的事

when
確定會發生

When I get home, I'll call you.

我到家的時候會打給你。
if
不一定會發生

If I get home before ten, I'll call you.

如果我十點前到家，會打給你。

例句

① 條件在前面

  1. If you tell them your reasons, they'll understand.
    如果你跟他們說你的理由，他們會理解的。
  2. If Mark gets the job, he'll buy a new car.
    如果 Mark 得到那份工作，他會買一輛新車。
  3. If we miss this train, we'll have to wait an hour.
    如果我們錯過這班火車，就得等一個小時。
  4. If you live in the countryside, you'll see a lot of wildlife.
    如果你住在鄉下，會看到很多野生動物。
  5. If the shop has my size, I'll buy those boots.
    如果那家店有我的尺寸，我會買那雙靴子。
  6. If she practises every day, she'll be ready for the concert.
    如果她每天練習，就能準備好參加音樂會。
  7. If you leave the milk out, it'll go off.
    如果你把牛奶放在外面，它會壞掉。

② 條件在後面

  1. I'll send you the photos if you give me your email.
    如果你給我電子郵件，我會把照片傳給你。
  2. Grandma will be pleased if you phone her on her birthday.
    如果你在奶奶生日那天打電話給她，她會很高興。
  3. We'll have the party in the garden if the weather is good.
    如果天氣好，我們會在花園辦派對。
  4. The plants will grow faster if you put them by the window.
    如果你把植物放在窗邊，它們會長得比較快。
  5. He'll be tired tomorrow if he stays up late.
    如果他熬夜，明天會很累。
  6. I'll make some soup if you're hungry.
    如果你餓了，我會煮點湯。

③ don't 和 won't

  1. If you don't take a map, you'll get lost.
    如果你不帶地圖，會迷路。
  2. If it doesn't rain soon, the river will dry up.
    如果不快點下雨，河會乾掉。
  3. If we don't book now, there won't be any seats left.
    如果我們現在不訂，就沒有位子了。
  4. If you eat all those sweets, you won't want your dinner.
    如果你把那些糖果都吃掉，就會不想吃晚餐。
  5. She won't come if you don't invite her.
    如果你不邀請她，她不會來。
  6. If he doesn't apologise, I won't speak to him again.
    如果他不道歉，我就再也不跟他說話。
  7. If they don't fix the heating, the office will be freezing tomorrow.
    如果他們不修暖氣，明天辦公室會冷得要命。

④ 問會怎麼樣

  1. What will you do if you don't get a place at university?
    如果你沒申請到大學，你會怎麼辦？
  2. Will you call me if you hear any news?
    如果你聽到任何消息，會打給我嗎？
  3. If it rains on Saturday, where will we have the picnic?
    如果星期六下雨，我們要在哪裡野餐？
  4. Who will look after the dog if you go away?
    如果你出遠門，誰會照顧狗？
  5. If the trains are on strike, how will you get to work?
    如果火車罷工，你要怎麼去上班？
  6. Will they be angry if we're late?
    如果我們遲到，他們會生氣嗎？

⑤ I'm sure、I think、probably

  1. I'm sure you'll love Rome if you go in the spring.
    我相信如果你春天去，一定會愛上羅馬。
  2. I think the teacher will let you leave early if you ask.
    我想如果你去問，老師會讓你早點走。
  3. I'm sure she'll help you if you explain the problem.
    我相信如果你把問題說清楚，她會幫你。
  4. I think we'll be late if we wait for Tom.
    我想如果我們等 Tom，會遲到。
  5. The team will probably win if Sara plays.
    如果 Sara 上場，球隊可能會贏。
  6. I'm sure your boss will understand if you need a day off.
    我相信如果你需要請一天假，你老闆會諒解的。
