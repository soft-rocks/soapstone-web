One more reason I like Singapore is that one sees cats everywhere.

我喜歡新加坡還有一個原因，就是到處都看得到貓。

one 泛⁠指任⁠何⁠人，動⁠詞用單⁠數

One more reason I like Singapore is that one sees cats everywhere.

……就是到處都看得到貓。

one、one's 和 oneself

One more reason I like Singapore is that one sees cats everywhere.

主詞 one

One should always tell the truth.

人應該永遠說實話。
所有格 one's

One must look after one's health.

人必須照顧好自己的健康。
反身代名詞 oneself

It is important to believe in oneself.

相信自己很重要。

One more reason I like Singapore is that one sees cats everywhere.

例句

① one + 單數動詞

  1. On television one can find almost anything, both good and bad.
    電視上幾乎什麼都看得到，好的壞的都有。
  2. One never knows who might be listening.
    誰都不知道會不會有人在偷聽。
  3. In London one hears many different languages.
    在倫敦可以聽到很多種不同的語言。
  4. One learns a great deal by travelling.
    人可以從旅行中學到很多。
  5. From the top of the hill, one can see the whole city.
    從山頂上可以看到整座城市。
  6. In a small town, one soon gets to know everybody.
    在小鎮裡，很快就會認識每個人。

② one + 情態動詞

  1. In this country, one must carry an identity card at all times.
    在這個國家，身上必須隨時帶著身分證。
  2. One must be careful when crossing this road.
    過這條馬路一定要小心。
  3. One cannot be too careful with money.
    用錢再怎麼小心都不為過。
  4. One ought to visit the museum at least once.
    這間博物館至少應該去一次。
  5. One might think that the job is easy, but it isn't.
    有人可能以為這份工作很輕鬆，其實不然。

③ one's + 名詞

  1. It is not easy to change one's habits.
    要改變自己的習慣不容易。
  2. One should always try one's hardest at work.
    人工作時應該盡全力。
  3. One's first job is often the hardest.
    人的第一份工作常常是最辛苦的。
  4. It is important to spend time with one's family.
    花時間陪家人很重要。
  5. One must pay one's taxes on time.
    人必須按時繳稅。

④ oneself

  1. It is hard to see oneself as others do.
    人很難用別人的眼光看自己。
  2. One must learn to laugh at oneself.
    人要學會自嘲。
  3. Living alone, one has to cook for oneself.
    一個人住，就得自己煮飯。
  4. It is healthy to give oneself a break sometimes.
    偶爾讓自己休息一下是好事。
  5. One should not compare oneself with others.
    人不應該拿自己跟別人比。

⑤ if one 和 when one

  1. If one wants to speak a language well, one must practise every day.
    想把一種語言說好，就必須每天練習。
  2. When one is young, one thinks that time is endless.
    年輕的時候，總以為時間用不完。
  3. If one is lucky, one can see dolphins near the coast.
    運氣好的話，可以在海岸附近看到海豚。
  4. When one travels abroad, one should respect local customs.
    出國旅行的時候，應該尊重當地的習俗。
  5. If one feels unwell, one should rest.
    如果覺得不舒服，就應該休息。

⑥ 正式的書面和演講

  1. One cannot help admiring the beauty of the old town.
    人不由得讚嘆老城區的美。
  2. As one gets older, one learns to be patient.
    人年紀愈大，就愈學會耐心。
  3. One hopes that the problem will soon be solved.
    希望這個問題很快就能解決。
  4. In such a beautiful place, one forgets all one's worries.
    在這麼美的地方，會忘掉所有的煩惱。
  5. Here one can enjoy fresh food at a reasonable price.
    在這裡可以用合理的價格吃到新鮮的食物。
