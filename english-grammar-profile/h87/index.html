If you wear white clothes, you will get paint on them.

如果你穿白色的衣服，衣服會沾到油漆。

if 子⁠句說未⁠來⁠的⁠事，還⁠是用現⁠在簡⁠單式

如果你穿白色的衣服，衣服會沾到油漆。

結⁠果可⁠以用 will、can 或祈⁠使⁠句

If you wear white clothes, you will get paint on them.

will

If you leave now, you'll catch the train.

你現在出門就趕得上火車。
can

If you need a lift, I can drive you.

如果你需要人載，我可以開車送你。
祈使句

If you see Tom, say hello from me.

如果你看到 Tom，幫我跟他問好。

每⁠次都⁠會這⁠樣⁠的⁠事，兩⁠邊都用現⁠在簡⁠單式

If you wear white clothes, you will get paint on them.

事實

If you leave ice in the sun, it melts.

冰放在太陽底下就會融化。

if 子⁠句放後⁠面⁠時不⁠加逗⁠號

If you wear white clothes, you will get paint on them.

在前

If you're hungry, there's some soup in the fridge.

如果你餓了，冰箱裡有湯。
在後

There's some soup in the fridge if you're hungry.

冰箱裡有湯，你餓了可以吃。

if 子⁠句⁠裡不⁠用 will

If you wear white clothes, you will get paint on them.

If it will rain tomorrow, we'll stay at home.

If it rains tomorrow, we'll stay at home.

if 子⁠句⁠的否⁠定要⁠有 don't

If you wear white clothes, you will get paint on them.

If you not hurry, you'll miss the bus.

If you don't hurry, you'll miss the bus.

例句

① If + 現在簡單式, will

  1. Wear your old jeans on Saturday. If you wear white clothes, you'll get paint on them.
    星期六穿你的舊牛仔褲來。如果你穿白色的衣服，衣服會沾到油漆。
  2. Take a jacket. If it gets cold, you'll be glad you have it.
    帶件外套。如果天氣變冷，你會慶幸有帶。
  3. It's four o'clock already. If we leave now, we'll get there before dark.
    已經四點了。如果我們現在出發，天黑前就會到。
  4. Think about who to go camping with. If you go with your parents, you'll go walking. If you go with friends, you'll have more fun.
    想想你要跟誰去露營。如果你跟爸媽去，你們會去健行。如果你跟朋友去，你會玩得比較開心。
  5. Don't worry. If the train is late, I'll wait for you at the station.
    別擔心。如果火車誤點，我會在車站等你。
  6. Her results come out next week. If she passes, she'll go to university in London.
    她的成績下星期出來。如果她考過，她就會去倫敦念大學。
  7. Be careful with that glass. If you drop it, it'll break.
    那個玻璃杯小心一點。你要是掉了，它會破。

② If + 現在簡單式, can / might

  1. Moving house is hard work. If you want some help, I can come next week.
    搬家很累。如果你需要幫忙，我下星期可以來。
  2. The forecast says sun. If the weather is nice, we can have lunch in the garden.
    氣象預報說會出太陽。如果天氣好，我們可以在花園吃午餐。
  3. Here's the deal. If you finish your homework, you can watch TV.
    我們說好了。你寫完功課，就可以看電視。
  4. It's a busy restaurant. If we don't book now, we might not get a table.
    那家餐廳很熱門。如果我們現在不訂，可能會沒位子。
  5. Ask the teacher. If she has time, she can explain it again.
    去問老師。如果她有空，她可以再解釋一次。

③ If + 現在簡單式, 祈使句

  1. I can't find Anna anywhere. If you see her, tell her to call me.
    我到處都找不到 Anna。如果你看到她，叫她打給我。
  2. You look pale. If you feel sick, go home and rest.
    你臉色好蒼白。如果你覺得不舒服，就回家休息。
  3. I made a cake this morning. If you're hungry, help yourself.
    我今天早上做了蛋糕。如果你餓了就自己拿。
  4. The streets here are confusing. Call me if you get lost.
    這裡的街道很亂。如果你迷路了就打給我。
  5. I'm going out now. If it rains, bring the washing in, please.
    我現在要出門。如果下雨，請把衣服收進來。

④ If + 現在簡單式, 現在簡單式

  1. My toothbrush is really important to me. If I don't have it, I can't clean my teeth.
    我的牙刷對我來說很重要。如果沒有它，我就沒辦法刷牙。
  2. Put the ice cream back in the freezer. If you leave ice in the sun, it melts.
    把冰淇淋放回冷凍庫。冰放在太陽底下就會融化。
  3. No coffee for me, thanks. If I drink coffee at night, I can't sleep.
    我不喝咖啡，謝謝。我晚上喝咖啡就會睡不著。
  4. Don't be scared. My dog barks if someone knocks on the door.
    別怕。有人敲門的話，我的狗就會叫。
  5. The baby missed her nap today. If she's tired, she cries a lot.
    寶寶今天沒睡午覺。她累了就會一直哭。

⑤ if 子句裡的否定

  1. It's ten past eight. If you don't hurry, you'll miss the bus.
    已經八點十分了。如果你不快一點，就會錯過公車。
  2. It's been dry for weeks. If it doesn't rain soon, the plants will die.
    已經好幾個星期沒下雨了。如果再不下雨，植物會死掉。
  3. That dress is very expensive. Don't buy it if you don't love it.
    那件洋裝很貴。如果你沒有很喜歡就別買。
  4. Here's Mr Lee's parcel. If he isn't at home, leave it with his neighbour.
    這是李先生的包裹。如果他不在家，就交給他鄰居。

⑥ if 子句在後面

  1. You look exhausted. You'll feel better if you get some sleep.
    你看起來累壞了。你睡一下就會好一點。
  2. Pack your swimsuit. We can go to the beach if the weather is good.
    帶上泳衣。如果天氣好，我們可以去海邊。
  3. Your car is at the garage? I'll lend you my bike if you need it.
    你的車在修車廠？如果你需要，我可以把腳踏車借你。
  4. I'm in the next room. Tell me if you need anything.
    我就在隔壁房間。如果你需要什麼就跟我說。
