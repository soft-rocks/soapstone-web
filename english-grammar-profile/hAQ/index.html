If you need anything else, you'll find it in the classroom.

如果你還需要什麼別的東西，教室裡都有。

不⁠定代⁠名⁠詞 + else

If you need anything else, you'll find it in the classroom.

如果你還需要什麼別的東西，教室裡都有。

指東⁠西、指⁠人、指地⁠方

If you need anything else, you'll find it in the classroom.

指東西

I'm full. I can't eat anything else.

我飽了，別的都吃不下了。
指人

Ask someone else. I'm busy.

去問別人，我在忙。
指地方

This café is full. Let's go somewhere else.

這家咖啡店客滿了，我們去別的地方吧。

別⁠人⁠的：else's

是別人的。

else 放⁠在⁠後⁠面

If you need anything else, you'll find it in the classroom.

Did you see else anybody at the station?

Did you see anybody else at the station?

不⁠定代⁠名⁠詞後⁠面不⁠用 other

If you need anything else, you'll find it in the classroom.

Let's talk about other something.

Let's talk about something else.

else 不⁠加 s

If you need anything else, you'll find it in the classroom.

Is there anything elses?

Is there anything else?

's 加在 else 後⁠面

I took someone's else umbrella by mistake.

I took someone else's umbrella by mistake.

other + 名⁠詞

這件毛衣你們有其他顏色嗎？

another + 單⁠數名⁠詞

我可以再拿一條毯子嗎？

例句

① something else

  1. This shirt is too small. Have you got something else?
    這件襯衫太小了。你們有別的嗎？
  2. I wanted to tell you something else.
    我還有別的事想跟你說。
  3. I'm tired of pasta. Can we cook something else tonight?
    我吃膩義大利麵了。今晚可以煮點別的嗎？
  4. He was thinking about something else.
    他在想別的事。
  5. Can we talk about something else, please?
    我們可以聊點別的嗎？

② anything else

  1. Would you like anything else with your coffee?
    你的咖啡還要搭點別的嗎？
  2. Is there anything else on the list?
    清單上還有別的嗎？
  3. I don't remember anything else about that night.
    那天晚上的事我別的都不記得了。
  4. Did he say anything else?
    他還有說別的嗎？
  5. We don't need anything else for the trip.
    這趟旅行我們不需要別的東西了。
  6. Anything else, madam?
    女士，還需要別的嗎？

③ someone else / somebody else

  1. This seat is taken. Somebody else is sitting here.
    這個位子有人了。有別人坐這裡。
  2. She's going out with someone else now.
    她現在跟別人在交往。
  3. Can somebody else help me with this box?
    有沒有其他人可以幫我搬這個箱子？
  4. I picked up someone else's keys.
    我拿錯了別人的鑰匙。
  5. Let someone else drive this time.
    這次讓別人開車吧。

④ everyone else / everything else

  1. Everyone else had already left.
    其他人都已經走了。
  2. I'll pay for the tickets. You pay for everything else.
    票錢我出，其他的你付。
  3. Everybody else in my class has a bike.
    我們班其他人都有腳踏車。
  4. Apart from the rain, everything else was perfect.
    除了下雨，其他都很完美。
  5. She arrived after everyone else.
    她比其他人都晚到。

⑤ nothing else / no one else

  1. There was nothing else in the box.
    箱子裡沒有別的東西了。
  2. No one else knows about this.
    這件事沒有其他人知道。
  3. I want this phone and nothing else.
    我只要這支手機，別的都不要。
  4. Nobody else wanted the job.
    沒有其他人想要這份工作。
  5. There's nothing else on TV.
    電視上沒有別的節目了。

⑥ somewhere else / anywhere else

  1. Can we sit somewhere else? It's too sunny here.
    我們可以坐別的地方嗎？這裡太曬了。
  2. You won't find cheaper shoes anywhere else.
    別的地方買不到更便宜的鞋子了。
  3. I'd like to live somewhere else one day.
    我希望有一天能住到別的地方去。
  4. Have you looked anywhere else?
    你有找過別的地方嗎？
  5. My cat won't sleep anywhere else.
    我的貓不肯睡在別的地方。
