It's a new flat, so there shouldn't be any problems.

這個你不應該錯過。

主⁠詞 + shouldn't + 原⁠形⁠動⁠詞

shouldn't / should not、shouldn't、there shouldn't be

shouldn't / should not不應該，或應該不會。
shouldn't口語常用的縮寫。
there shouldn't be應該不會有。

不⁠應⁠該和應⁠該不⁠會

不應該

You shouldn't eat so much sugar.

你不應該吃那麼多糖。
應該不會

The test shouldn't be difficult.

考試應該不會很難。

I think you shouldn't 和 I don't think you should

例句

I don't think you should go.

我覺得你不應該去。

兩種說法都可以。英文比較常用 I don't think you should。

should 的否⁠定是 should not 或 shouldn't

It's a new flat, so there shouldn't be any problems.

You don't should miss it.

You shouldn't miss it.

not 放⁠在 should 後⁠面

You not should wear that.

You should not wear that.

shouldn't 後⁠面直⁠接接原⁠形⁠動⁠詞

It's a new flat, so there shouldn't be any problems.

There shouldn't to be any problems.

There shouldn't be any problems.

例句

① There shouldn't be + 名詞：應該不會有

  1. We've rented a brand-new flat, so there shouldn't be any problems with the heating.
    我們租了一間全新的公寓，所以暖氣應該不會有任何問題。
  2. We booked the tickets weeks ago, so there shouldn't be a problem at the door.
    我們幾個星期前就訂了票，所以門口應該不會有問題。
  3. It's a quiet road, so there shouldn't be much traffic in the morning.
    那是一條安靜的路，所以早上應該不會有很多車。
  4. The forecast is good, so there shouldn't be any rain on the wedding day.
    天氣預報很好，所以婚禮那天應該不會下雨。
  5. The office is closed on Sunday, so there shouldn't be anyone there.
    辦公室星期天不開，所以那裡應該不會有人。
  6. We've got plenty of chairs, so there shouldn't be any trouble finding a seat.
    我們有很多椅子，所以應該不會找不到位子。

② You shouldn't + 原形動詞：勸對方不要做

  1. It's the best film of the year. You shouldn't miss it.
    那是今年最好的電影。你不應該錯過。
  2. You shouldn't wear your favourite clothes to the farm because they might get dirty.
    你不應該穿你最喜歡的衣服去農場，因為可能會弄髒。
  3. You shouldn't leave your bag on the chair in a busy café.
    在人很多的咖啡館裡，你不應該把包包放在椅子上。
  4. The sea is very rough today. You shouldn't go out in that little boat.
    今天海浪很大。你不應該坐那艘小船出海。
  5. You shouldn't stay up so late before your driving test.
    考駕照前你不應該熬夜到那麼晚。
  6. You shouldn't lend your bike to people you don't know.
    你不應該把腳踏車借給你不認識的人。

③ 主詞 + shouldn't + 原形動詞：應該不會

  1. The bus comes every ten minutes, so we shouldn't have to wait long.
    公車每十分鐘一班，所以我們應該不用等很久。
  2. The exam is on things we've practised, so it shouldn't be too difficult.
    考試考的是我們練習過的東西，所以應該不會太難。
  3. The repair is quite simple, so it shouldn't cost very much.
    修理很簡單，所以應該不會花很多錢。
  4. The journey is only an hour, so the children shouldn't get bored.
    路程只有一個小時，所以孩子們應該不會覺得無聊。
  5. The paint is dry now, so it shouldn't mark your clothes.
    油漆現在乾了，所以應該不會弄髒你的衣服。
  6. My sister knows the way, so she shouldn't get lost.
    我姊姊認得路，所以她應該不會迷路。

④ 主詞 + should not + 原形動詞：規定和正式的建議

  1. Hikers should not leave the marked path in foggy weather.
    起霧的時候，健行的人不應該離開標示的步道。
  2. Medicine should not be left where children can reach it.
    藥不應該放在孩子拿得到的地方。（被動）
  3. Drivers should not park in front of the fire station.
    駕駛不應該把車停在消防局前面。
  4. Visitors should not feed the animals in the zoo.
    參觀者不應該餵動物園裡的動物。
  5. Food should not be kept in the fridge for more than three days.
    食物不應該放在冰箱超過三天。（被動）
  6. Young children should not walk to school alone.
    小孩子不應該一個人走路上學。

⑤ I don't think + 主詞 + should + 原形動詞

  1. I don't think you should buy that coat. It's too big for you.
    我覺得你不應該買那件外套。它對你來說太大了。
  2. I don't think we should tell Mum about the broken plate yet.
    我覺得我們還不應該告訴媽媽盤子破掉的事。
  3. I don't think she should drive in this snow.
    我覺得她不應該在這種雪裡開車。
  4. I don't think they should build a car park on the football field.
    我覺得他們不應該在足球場上蓋停車場。
  5. I don't think you should eat that. It smells strange.
    我覺得你不應該吃那個。它聞起來很怪。
  6. I don't think he should leave school at sixteen.
    我覺得他不應該十六歲就離開學校。
  7. I don't think we should go out in this storm.
    我覺得我們不應該在這種暴風雨裡出門。
