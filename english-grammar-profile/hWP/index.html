I'm not going to be able to meet you next Tuesday, because I have to go to the dentist.

我下週二沒辦法跟你見面，因為我得去看牙醫。

主⁠詞 + am / is / are + not + going to + 原⁠形⁠動⁠詞

I'm not going to be able to meet you next Tuesday, because I have to go to the dentist.

not going to主詞決定不做，或計畫做不成。
原形動詞不打算做的事。

說不⁠打⁠算做⁠的事

例句

I'm not going to buy a new phone this year.

我今年不打算買新手機。

說話者已經決定不做某件事。

not going to be able to：計⁠畫做不⁠成

I'm not going to be able to meet you next Tuesday, because I have to go to the dentist.

例句

We aren't going to be able to come to the wedding.

我們沒辦法去參加婚禮。

說話者想做，可是因為別的事做不成。

否⁠定用 be 動⁠詞加 not

I'm not going to be able to meet you next Tuesday, because I have to go to the dentist.

I don't going to stay here forever.

I'm not going to stay here forever.

going to 後⁠面⁠接原⁠形⁠動⁠詞 be，再⁠接 able to

I'm not going to be able to meet you next Tuesday, because I have to go to the dentist.

I'm not going to able to come.

I'm not going to be able to come.

not 放⁠在 be 動⁠詞後⁠面，going 前⁠面

I'm not going to be able to meet you next Tuesday, because I have to go to the dentist.

She is going not to come.

She is not going to come.

例句

① 不打算做的事：be not going to + 原形動詞

  1. I'm sure I'm not going to live in this town forever.
    我確定我不會一輩子住在這個小鎮。
  2. I'm not going to watch that film again.
    那部電影我不打算再看了。
  3. She isn't going to leave her job.
    她不打算辭職。
  4. We aren't going to paint the kitchen this summer.
    我們今年夏天不打算油漆廚房。
  5. He's not going to apologise to anyone.
    他不打算跟任何人道歉。
  6. They aren't going to take the kids on holiday this year.
    他們今年不打算帶孩子去度假。
  7. I'm not going to answer that question.
    我不打算回答那個問題。
  8. My brother isn't going to join us for lunch.
    我哥不會跟我們一起吃午餐。
  9. We're not going to spend all our savings on a car.
    我們不打算把存款全花在一台車上。
  10. I'm not going to make the same mistake twice.
    我不會犯同樣的錯兩次。
  11. She's not going to wear a dress to the party.
    她不打算穿洋裝去派對。
  12. They're not going to cut down the old oak tree.
    他們不打算砍掉那棵老橡樹。
  13. I'm not going to argue with you.
    我不打算跟你吵。
  14. Our neighbours aren't going to sell their house after all.
    我們的鄰居最後不打算賣房子了。
  15. He isn't going to play in Saturday's match.
    他不打算參加星期六的比賽。
  16. I'm not going to eat out this week.
    我這週不打算在外面吃飯。

② 計畫做不成：be not going to be able to + 原形動詞

  1. I'm not going to be able to finish this report by Friday.
    我星期五之前沒辦法寫完這份報告。
  2. We aren't going to be able to visit you this weekend, because our car has broken down.
    我們這個週末沒辦法去看你，因為我們的車壞了。
  3. She isn't going to be able to sing tonight, because she has a sore throat.
    她今晚沒辦法唱歌，因為她喉嚨痛。
  4. I'm not going to be able to lend you the money.
    我沒辦法借你這筆錢。
  5. They aren't going to be able to fix the roof before the rain.
    他們沒辦法在下雨前修好屋頂。
  6. He isn't going to be able to drive for a few weeks.
    他有幾個星期沒辦法開車。
  7. I'm not going to be able to take you to the station tomorrow.
    我明天沒辦法載你去車站。
  8. We're not going to be able to afford a holiday this year.
    我們今年負擔不起去度假。
  9. The team isn't going to be able to play without its captain.
    少了隊長，這支隊伍沒辦法比賽。
  10. I'm not going to be able to answer all your emails today.
    我今天沒辦法回覆你所有的電子郵件。
  11. You aren't going to be able to park outside the hospital.
    你沒辦法把車停在醫院外面。
  12. She's not going to be able to come to the meeting, because her flight is late.
    她沒辦法來開會，因為她的班機誤點了。
  13. I'm not going to be able to help you move house on Sunday.
    我星期天沒辦法幫你搬家。
  14. We aren't going to be able to get tickets for the final.
    我們買不到決賽的票。
  15. My parents aren't going to be able to pick me up after school.
    我爸媽放學後沒辦法來接我。
