The weather is still warm, so we should be able to visit the beaches.

應該會是很棒的一天！

主⁠詞 + should + 原⁠形⁠動⁠詞

should、原⁠形⁠動⁠詞

should應該會。根據情況推論。
原形動詞推論會發生的事。

義⁠務和可⁠能⁠性

The weather is still warm, so we should be able to visit the beaches.

建議

You should rest.

你應該休息。
可能性

It should be a good day.

應該會是很棒的一天。

should 可以說建議，也可以說可能性。

should be able to

The weather is still warm, so we should be able to visit the beaches.

例句

We should be able to finish by six.

我們應該能在六點前完成。

should be able to 說應該能夠做某件事。

名⁠詞或形⁠容⁠詞前⁠面要⁠有 be

The weather is still warm, so we should be able to visit the beaches.

It should a good day.

It should be a good day.

be able 後⁠面要接 to

The weather is still warm, so we should be able to visit the beaches.

We should be able visit the beach.

We should be able to visit the beach.

should 後⁠面⁠接原⁠形 be

The weather is still warm, so we should be able to visit the beaches.

The test should is easy.

The test should be easy.

例句

① It should be + 形容詞或名詞：推論活動會怎樣

  1. Everyone is coming to the school fair, and the forecast is sunny. It should be a good day!
    大家都會來學校園遊會，天氣預報也是晴天。應該會是很棒的一天！
  2. The band is great live. It should be a fun concert.
    那個樂團現場很棒。應該會是一場好玩的演唱會。
  3. The teams are very close in the league. It should be an exciting match.
    這兩隊在聯賽裡很接近。應該會是一場刺激的比賽。
  4. The new restaurant has good reviews. It should be a nice evening.
    那家新餐廳評價很好。應該會是一個愉快的晚上。
  5. The road is flat all the way. It should be an easy bike ride.
    那條路一路都是平的。騎腳踏車應該很輕鬆。
  6. The guide knows the city very well. It should be an interesting tour.
    導遊對這個城市很熟。應該會是一次有趣的導覽。

② 主詞 + should be able to + 原形動詞：應該能夠

  1. In September the weather is still warm, so we should be able to visit the beaches and go sightseeing in the evenings.
    九月天氣還很暖和，所以我們白天應該可以去海灘，晚上去觀光。
  2. The train is fast, so we should be able to get there by lunchtime.
    火車很快，所以我們應該能在午餐前到。
  3. With three of us working, we should be able to finish the painting today.
    我們三個人一起做，應該今天就能漆完。
  4. The shop opens at nine, so you should be able to buy it in the morning.
    那家店九點開門，所以你早上應該就能買到。
  5. My English is better now, so I should be able to understand the film.
    我的英文現在比較好了，所以我應該看得懂那部電影。
  6. The hotel has a big car park, so we should be able to park easily.
    飯店有很大的停車場，所以我們應該很好停車。

③ 主詞 + should + 原形動詞：推論時間和結果

  1. The parcel was sent on Monday, so it should arrive tomorrow.
    包裹星期一寄出，所以應該明天會到。
  2. If we leave now, we should get there before dark.
    如果我們現在出發，應該天黑前會到。
  3. The medicine should start working in about an hour.
    藥大約一個小時後應該會開始有效。
  4. The shop said the repairs should take about a week.
    那家店說修理大概要一個星期。
  5. The meeting should finish at around four.
    會議應該大約四點結束。
  6. The roads should be quiet on a Sunday morning.
    星期天早上路上應該很空。

④ 主詞 + should be + 形容詞：推論現在的情況

  1. She left an hour ago, so she should be at the station by now.
    她一個小時前走的，所以現在應該到車站了。
  2. The cake has been in the oven for forty minutes. It should be ready.
    蛋糕在烤箱裡四十分鐘了。應該好了。
  3. Ask Tom. He should know the answer. He studied history.
    問湯姆。他應該知道答案。他念歷史的。
  4. The water should be warm enough for swimming now.
    現在水應該夠暖，可以游泳了。
  5. The tickets should be in your email. Check your inbox.
    票應該在你的電子郵件裡。看一下你的收件匣。
  6. The new manager should be here on Monday.
    新經理星期一應該會到。

⑤ There should be + 名詞：推論應該有

  1. It's a popular route, so there should be plenty of buses.
    那是熱門路線，所以應該有很多班公車。
  2. The museum is big, so there should be a café inside.
    博物館很大，所以裡面應該有咖啡館。
  3. We booked early, so there should be good seats left.
    我們很早就訂了，所以應該還有好位子。
  4. There should be enough cake for everyone if we cut small pieces.
    如果切小塊一點，蛋糕應該夠每個人吃。
  5. It's a big hotel, so there should be a lift.
    那是一家大飯店，所以應該有電梯。
  6. There should be a cash machine near the market.
    市場附近應該有提款機。
  7. After all the rain, there should be lots of mushrooms in the woods.
    下了那麼多雨，樹林裡應該有很多蘑菇。
