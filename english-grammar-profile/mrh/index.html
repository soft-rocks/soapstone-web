which 指前⁠面整⁠句話⁠說⁠的事

現在寄出一封信，十分鐘內就能收到回覆，這是件好事。

which is / was 加形⁠容⁠詞或名⁠詞片⁠語，說⁠出看⁠法

It is now possible to send a letter and receive an answer within ten minutes, which is a good thing.

看法

The train was half an hour late, which was really annoying.

火車誤點半小時，真的很煩。
看法

She remembered my birthday, which was very sweet of her.

她記得我的生日，她真貼心。

which means 說⁠明這⁠件⁠事帶⁠來⁠的結⁠果

It is now possible to send a letter and receive an answer within ten minutes, which is a good thing.

結果

The bridge is closed, which means we'll have to take the long way.

橋封閉了，也就是說我們得繞遠路。

which 可⁠以指一⁠個名⁠詞，也⁠可⁠以指整⁠個子⁠句

It is now possible to send a letter and receive an answer within ten minutes, which is a good thing.

指名詞

He gave me a book, which was about Japan.

他給了我一本書，那本書是講日本的。
指整個子句

He gave me a book, which was kind of him.

他給了我一本書，他人真好。

指前⁠面整⁠件⁠事用 which，不⁠用 what

It is now possible to send a letter and receive an answer within ten minutes, which is a good thing.

He passed all his exams, what surprised everyone.

He passed all his exams, which surprised everyone.

指整⁠個子⁠句只⁠能用 which，不⁠用 that

It is now possible to send a letter and receive an answer within ten minutes, which is a good thing.

It rained all weekend, that was disappointing.

It rained all weekend, which was disappointing.

which 就⁠是主⁠詞，不⁠再⁠加 it

It is now possible to send a letter and receive an answer within ten minutes, which is a good thing.

We missed the bus, which it made us late.

We missed the bus, which made us late.

指整⁠個子⁠句⁠的 which 前⁠面要加逗⁠號

It is now possible to send a letter and receive an answer within ten minutes, which is a good thing.

She called me back immediately which was nice.

She called me back immediately, which was nice.

例句

① which is / was + 形容詞

  1. The museum is free on Sundays, which is great for families.
    博物館星期天免費，對家庭來說很棒。
  2. He didn't even say goodbye, which was rude.
    他連再見都沒說，真沒禮貌。
  3. My neighbors are moving away, which is sad.
    我的鄰居要搬走了，好難過。
  4. The tickets sold out in five minutes, which was incredible.
    票五分鐘就賣完了，太誇張了。
  5. They gave us a free upgrade, which was very generous.
    他們幫我們免費升等，真大方。
  6. She speaks four languages, which is impressive.
    她會說四種語言，真厲害。

② which is / was + 名詞片語

  1. We finished the project early, which was a big relief.
    我們提早完成了計畫，總算鬆了一口氣。
  2. The shop has started selling local fruit, which is a great idea.
    那家店開始賣本地水果了，這個主意很好。
  3. I forgot my umbrella, which was a mistake.
    我忘了帶傘，真是失策。
  4. The kids cleaned their room without anyone asking them, which was a nice surprise.
    孩子們沒人叫就自己整理了房間，真是驚喜。
  5. Prices keep going up, which is a real problem for students.
    物價一直漲，對學生來說是個大問題。
  6. He apologized in front of everyone, which was a brave thing to do.
    他當著大家的面道歉，這需要勇氣。

③ which means / makes / explains

  1. Our flight leaves at 6 a.m., which means getting up at three.
    我們的班機早上六點起飛，也就是說要三點起床。
  2. She's been working twelve-hour days, which explains why she looks so tired.
    她每天工作十二個小時，難怪她看起來那麼累。
  3. The heating is broken, which makes the office freezing.
    暖氣壞了，辦公室冷得要命。
  4. The café opens at seven, which means I can have breakfast before work.
    那家咖啡店七點開，所以我上班前可以吃早餐。
  5. He's lived in Spain for ten years, which explains his accent.
    他在西班牙住了十年，難怪他有那種口音。

④ which + 其他動詞

  1. Nobody came to the meeting, which surprised the manager.
    沒有人來開會，讓經理很驚訝。
  2. My brother lent me his car, which helped a lot.
    我哥哥借我他的車，幫了我很大的忙。
  3. They changed the timetable again, which confused everyone.
    他們又改了時刻表，讓大家都搞不清楚。
  4. She laughed at my idea, which hurt my feelings.
    她笑我的點子，讓我很受傷。
  5. The baby slept through the night, which made us very happy.
    寶寶一覺睡到天亮，讓我們很開心。

⑤ 不同的情境

  1. You can return the shoes within thirty days, which is useful if they don't fit.
    鞋子三十天內可以退，不合腳的話很方便。
  2. The boss specified every detail of the report, which saved us a lot of time.
    老闆把報告的每個細節都說清楚了，替我們省了很多時間。
  3. My parents finally reconciled, which I never expected.
    我爸媽終於和好了，我從來沒想到會這樣。
  4. Zoos help us learn about animals, which is important for protecting them.
    動物園幫助我們了解動物，這對保護牠們很重要。
  5. The concert was outdoors, which was perfect on such a warm night.
    演唱會在戶外，在那麼溫暖的夜晚真是再好不過了。
  6. He agreed to help us, which I thought was very kind.
    他答應幫我們，我覺得他人很好。
  7. The library now stays open until midnight, which suits students perfectly.
    圖書館現在開到半夜，對學生來說再適合不過了。
  8. I got the last seat on the bus, which was lucky.
    我搶到公車上最後一個位子，運氣真好。
