我們在門口等，可是沒有人來。

例句

① there was / there were none

  1. The brochure promised free parking, but there was none.
    小冊子說有免費停車位，結果根本沒有。
  2. We wanted a table for six, but there were none free.
    我們想要一張六人桌，可是都沒空位。
  3. I looked for a mistake in his report, but there was none.
    我在他的報告裡找錯誤，可是一個也沒找到。
  4. The guide mentioned a gift shop, but there was none.
    導遊說有紀念品店，結果並沒有。
  5. They said there would be a discount for students, but there was none.
    他們說學生有折扣，結果沒有。
  6. We hoped for some snow at Christmas, but there was none.
    我們希望聖誕節會下雪，結果一點也沒下。

② 動詞 + none

  1. I asked three shops for a box, but found none.
    我問了三家店要箱子，一個也沒拿到。
  2. The company promised a refund, but we've received none.
    公司答應退款，可是我們一毛也沒收到。
  3. He asked for help from his colleagues and got none.
    他向同事求助，可是沒有人幫他。
  4. We searched the beach for shells but saw none.
    我們在海灘上找貝殼，一個也沒看到。
  5. Investors expected a profit this year, but the firm made none.
    投資人預期今年會有獲利，結果公司一點也沒賺。

③ none 當主詞

  1. Several solutions were suggested. None worked.
    有人提出了幾個辦法，可是沒有一個有用。
  2. We sent out fifty invitations, and none was returned.
    我們寄出了五十張邀請函，一張都沒退回。
  3. Lots of trains run on this line, but none stops here at night.
    這條線有很多火車，可是晚上沒有一班停這站。
  4. I've tried many diets, and none has worked for long.
    我試過很多種減肥方法，沒有一種長久有效。
  5. The hotel has four lifts, but none is working today.
    飯店有四部電梯，今天卻一部都不能用。

④ none at all、almost none

  1. We were told to expect delays, but there were none at all.
    我們被告知會誤點，結果完全沒有。
  2. There used to be many shops here, but now there are almost none.
    這裡以前有很多店，現在幾乎沒有了。
  3. Do I have any regrets? None at all.
    我有沒有後悔？完全沒有。
  4. Some flats here have a balcony, but most have none.
    這裡有些公寓有陽台，大部分都沒有。
  5. The village had very little electricity, and some homes had none.
    這個村子電力很少，有些人家完全沒電。

⑤ 回答和表格

  1. "How many messages did I get?" "None, I'm afraid."
    我收到幾則訊息？恐怕一則也沒有。
  2. Under "allergies" on the form, she wrote "none".
    她在表格的過敏欄寫了無。
  3. "Any calls while I was out?" "None."
    我出去的時候有人打電話來嗎？沒有。
  4. "Have you got any luggage to check in?" "None, just this bag."
    有行李要托運嗎？沒有，只有這個包包。
  5. "How many complaints did we get this week?" "None. It was a quiet week."
    這週收到幾件客訴？一件也沒有，這週很平靜。

⑥ 正式的寫作

  1. The course description mentioned a trip to London, but there was none.
    課程介紹提到倫敦之旅，結果沒有安排。
  2. The report found clear benefits for some patients but none for others.
    報告發現這對某些病人有明顯的好處，對其他病人則完全沒有。
  3. We asked for an explanation of the delay, but none was given.
    我們要求說明延誤的原因，可是對方沒有給任何解釋。
  4. The advert promised a guide on every tour, but there was none on ours.
    廣告說每個行程都有導遊，我們的行程卻沒有。
  5. Many students wanted evening classes, but the school offered none.
    很多學生想上夜間課程，可是學校一堂也沒開。
