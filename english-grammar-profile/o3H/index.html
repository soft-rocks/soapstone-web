If possible, I'd like to come to see you on Tuesday afternoon.

可以的話，我想星期二下午去看你。

I'd like to + 原⁠形⁠動⁠詞

would like、if possible

would like想要。說願望和偏好。
if possible如果可以的話。讓請求更客氣。

點餐

例句

I would like the chicken, please.

我要雞肉，謝謝。

在餐廳點餐時，常用 I would like 加食物。

說偏⁠好

例句

I'd like the window seat, if possible.

如果可以，我想要靠窗的位子。

說自己比較想要哪一個時，也可以用 would like。

例句

① If possible, + I'd like to + 原形動詞：客氣地說希望的安排

  1. I don't have classes on Tuesday. If possible, I'd like to come to see you on Tuesday afternoon.
    我星期二沒有課。如果可以的話，我想星期二下午去找您。
  2. If possible, I'd like to change my appointment to Thursday.
    如果可以的話，我想把預約改到星期四。
  3. If possible, I'd like to sit near the front of the class.
    如果可以的話，我想坐在教室前面。
  4. If possible, I'd like to start the new job in September.
    如果可以的話，我想九月開始新工作。
  5. If possible, I'd like to pay in two parts.
    如果可以的話，我想分兩次付款。
  6. If possible, I'd like to have a room on the ground floor.
    如果可以的話，我想要一樓的房間。

② I would like + 食物：點餐

  1. For my main course, I would like the chicken with potatoes and some vegetables.
    主菜我要雞肉配馬鈴薯和一些蔬菜。
  2. I would like the tomato soup to start, please.
    前菜我要番茄湯，謝謝。
  3. I'd like a cheese sandwich and a cup of tea.
    我要一個起司三明治和一杯茶。
  4. My son would like the pasta with no sauce.
    我兒子要不加醬的義大利麵。
  5. I'd like a large orange juice, please.
    請給我一大杯柳橙汁。
  6. We would like two coffees and a piece of chocolate cake.
    我們要兩杯咖啡和一塊巧克力蛋糕。

③ I'd like + 名詞, if possible：說偏好

  1. I'd like the window seat, if possible.
    如果可以，我想要靠窗的位子。
  2. I'd like a quiet room at the back of the hotel, if possible.
    如果可以，我想要飯店後面安靜的房間。
  3. My eyes get tired on screens. I'd like a paper copy of the report, if possible.
    我的眼睛看螢幕會累。如果可以，我想要一份紙本報告。
  4. I'd like the blue one, if possible. It's my favourite colour.
    如果可以，我想要藍色那個。那是我最喜歡的顏色。
  5. We'd like a table outside, if possible.
    如果可以，我們想要外面的桌子。
  6. I'd like a single room for three nights, if possible.
    如果可以，我想要一間單人房住三晚。

④ I'd like to + 原形動詞 + one day：說願望

  1. I'd like to travel around South America one day.
    我希望有一天能環遊南美洲。
  2. I'd like to learn to speak Japanese one day.
    我希望有一天能學會說日文。
  3. I'd like to have my own restaurant one day.
    我希望有一天能有自己的餐廳。
  4. I'd like to see the Northern Lights one day.
    我希望有一天能看到北極光。
  5. I'd like to write a book about my grandmother's life one day.
    我希望有一天能寫一本關於我奶奶一生的書。
  6. I'd like to run a marathon one day.
    我希望有一天能跑一場馬拉松。

⑤ 主詞 + would like + to + 原形動詞：說別人的願望

  1. My mum would like to retire to a small village by the sea.
    我媽媽想退休後搬到海邊的小村子。
  2. My best friend would like to become a vet.
    我最好的朋友想當獸醫。
  3. The children would like to spend the afternoon at the park.
    孩子們想在公園度過下午。
  4. My dad would like to go fishing on Sunday morning.
    我爸爸星期天早上想去釣魚。
  5. Our teacher would like to take us to the science museum.
    我們老師想帶我們去科學博物館。
  6. My grandparents would like to celebrate their anniversary in Paris.
    我的祖父母想在巴黎慶祝他們的結婚紀念日。
  7. My sister would like to have a big wedding in the summer.
    我姊姊想在夏天辦一個盛大的婚禮。
