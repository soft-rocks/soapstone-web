例句

① It would be great / nice if + 過去簡單式

  1. It would be great if you sent me a few photos from the trip.
    你要是能寄幾張旅行的照片給我，那就太好了。
  2. It would be nice if you came to the party on Saturday.
    你星期六要是能來派對就好了。
  3. It would be great if we met before the meeting to go through the plan.
    開會前我們要是能先碰面討論一下計畫，就太好了。
  4. It would be nice if you called your grandmother more often.
    你要是能多打電話給奶奶就好了。

② It would be helpful if + 過去簡單式

  1. I think it would be very helpful if I told you about my own case.
    我想，要是我跟您說說我自己的情況，應該會很有幫助。
  2. It would be helpful if you brought your passport on the first day.
    第一天如果你能帶護照來，會很有幫助。
  3. It would be helpful if everyone arrived ten minutes early.
    如果大家都能提早十分鐘到，會很有幫助。
  4. It would be really helpful if you explained the rules again.
    你要是能再解釋一次規則，就幫了大忙了。

③ I would be grateful if + 過去簡單式

  1. I would be grateful if you gave me this job.
    如果您能給我這份工作，我會非常感激。
  2. I would be grateful if you sent me more information about the course.
    如果您能寄更多課程的資料給我，我會很感激。
  3. I would be grateful if you refunded the full price of the ticket.
    如果您能全額退還票價，我會很感激。
  4. We would be grateful if you kept this information private.
    如果您能對這件事保密，我們會很感激。
  5. I'd be very grateful if you didn't mention this to my boss.
    你要是別跟我老闆提這件事，我會很感激。

④ I would appreciate it if + 過去簡單式

  1. I would appreciate it if you replied by Friday.
    如果您能在星期五前回覆，我會很感謝。
  2. I'd appreciate it if you turned the music down a bit.
    你要是能把音樂關小聲一點，我會很感謝。
  3. We would appreciate it if you paid the bill within thirty days.
    如果您能在三十天內付款，我們會很感謝。
  4. I'd really appreciate it if you were a little more forthright with me.
    你要是能對我再直接一點，我會很感謝。

⑤ Would you mind if I + 過去簡單式

  1. Would you mind if I opened the window?
    我開個窗戶，你介意嗎？
  2. Would you mind if I left a bit early today?
    我今天早一點走，你介意嗎？
  3. Would you mind if we changed the date of the interview?
    我們改一下面試的日期，您介意嗎？
  4. Would you mind if I asked you a personal question?
    我問你一個私人的問題，你介意嗎？

⑥ if 子句用 were

  1. It would be wonderful if you were able to join us for dinner.
    您要是能跟我們一起吃晚餐，那就太好了。
  2. I would be grateful if you were available for a short call next week.
    如果您下禮拜有空簡短通個電話，我會很感激。
  3. It would help a lot if the room were ready by nine.
    房間要是能在九點前準備好，就幫了大忙了。
  4. It would be easier for everyone if you were here on time.
    你要是準時到，大家都會輕鬆一點。

⑦ 用在書信和電子郵件

  1. It would be very kind of you if you forwarded my letter to the manager.
    如果您能把我的信轉給經理，那就太感謝了。
  2. I would be grateful if you considered my application for the post of assistant.
    如果您能考慮我應徵助理一職的申請，我會很感激。
  3. It would be useful if you included a map with the invitation.
    如果您能在邀請函裡附上地圖，會很方便。
  4. We would be grateful if all members returned the form by the end of the month.
    如果所有會員能在月底前交回表格，我們會很感激。
  5. I would appreciate it if you checked my booking and confirmed the dates.
    如果您能查一下我的訂位並確認日期，我會很感謝。
  6. It would be great if you let me know as soon as possible.
    您要是能儘快通知我，那就太好了。
