If I have spare time, I always read a book.

只要有空，我都會看書。

if 子⁠句用現⁠在簡⁠單式說真⁠實⁠的條⁠件

If I have spare time, I always read a book.

如果午餐後覺得累，我通常會去散個步。

現⁠在簡⁠單式說習⁠慣

If I have spare time, I always read a book.

習慣

If it's cold, my dad always wears his old hat.

天冷的時候，我爸總是戴他那頂舊帽子。

這時 if 的意思接近 when 或 whenever。

主⁠要⁠子⁠句用 can 或祈⁠使⁠句

can

If you have a student card, you can get in for free.

如果你有學生證，就可以免費入場。
祈使句

If you need more information, call the office.

如果你需要更多資料，就打電話到辦公室。

主⁠要⁠子⁠句說現⁠在⁠的情⁠況

be 動詞

If you need help, I'm in the next room.

如果你需要幫忙，我就在隔壁房間。

if 子⁠句放⁠在⁠後⁠面

前面不加逗號

Leo gets angry if he loses at cards.

Leo 玩牌輸了就會生氣。

原句：有⁠空就看書

If I have spare time, I always read a book.

只要有空，我都會看書。

這裡的 if 意思接近 whenever。

第⁠三⁠人⁠稱單⁠數⁠的動⁠詞加 ⁠-⁠s

If I have spare time, I always read a book.

If my sister has time, she always cook dinner.

If my sister has time, she always cooks dinner.

if 子⁠句不⁠用 will

If I have spare time, I always read a book.

If you will need the car tonight, tell me now.

If you need the car tonight, tell me now.

always 放⁠在一⁠般動⁠詞前⁠面

If I have spare time, I always read a book.

If I have time, I read always the news.

If I have time, I always read the news.

will 說未⁠來某一⁠次

現在簡單式
每次都會

If it rains, we play cards indoors.

下雨的時候，我們會在室內玩牌。
will
未來某一次

If it rains tomorrow, we'll go to the museum instead.

如果明天下雨，我們就改去博物館。

過⁠去簡⁠單式說不⁠是事⁠實⁠的情⁠況

現在簡單式
真的會發生

If I have time, I read.

我有時間就會看書。
過去簡單式
不是事實

If I had time, I would read more.

要是我有時間，我會多看點書。

例句

① 習慣和每次都會發生的事

  1. If my train is late, I usually get a coffee at the station.
    如果火車誤點，我通常會在車站買杯咖啡。
  2. If it's sunny, we often have lunch on the balcony.
    天氣好的話，我們常在陽台吃午餐。
  3. If Tom can't sleep, he listens to the radio.
    Tom 睡不著的時候，會聽收音機。
  4. If I eat too late, I sleep badly.
    如果我太晚吃東西，就會睡不好。
  5. If the baby cries at night, my husband usually gets up.
    寶寶晚上哭的話，通常是我先生起來。
  6. If we go to the cinema, we always buy popcorn.
    我們去看電影的話，都會買爆米花。
  7. If my grandma visits, she brings a cake.
    奶奶來的話，都會帶蛋糕。

② can 說可以做的事

  1. If you have a library card, you can borrow six books.
    如果你有借書證，可以借六本書。
  2. If you're over sixty, you can travel free on the bus.
    如果你超過六十歲，可以免費搭公車。
  3. If it's not too windy, the children can play on the beach.
    如果風不太大，孩子們可以在海灘玩。
  4. If you book online, you can choose your seat.
    如果你在網路上訂，可以自己選位子。
  5. If the door is locked, you can use the back entrance.
    如果門鎖著，你可以走後門。
  6. If you live near the school, you can walk there.
    如果你住在學校附近，可以走路去。
  7. If you don't understand a word, you can look it up.
    如果你看不懂某個字，可以查一查。

③ 祈使句

  1. If you need to contact me, just call my mobile.
    如果你需要聯絡我，打我手機就好。
  2. If you're cold, put on a jumper.
    如果你冷，就穿件毛衣。
  3. If the phone rings, don't answer it.
    如果電話響了，別接。
  4. If you see smoke, leave the building at once.
    如果你看到煙，馬上離開大樓。
  5. If you have any questions, ask Maria.
    如果你有任何問題，問 Maria。
  6. If the milk smells bad, throw it away.
    如果牛奶聞起來壞了，就丟掉。

④ 告訴對方去哪裡找

  1. If you need some help, I'm here.
    如果你需要幫忙，我在這裡。
  2. If you want the keys, they're on the kitchen table.
    如果你要鑰匙，就在廚房桌上。
  3. If you need a pen, there's one in my bag.
    如果你需要筆，我包包裡有一支。
  4. If you like Italian food, there's a great restaurant round the corner.
    如果你喜歡義大利菜，轉角有家很棒的餐廳。
  5. If you're hungry, there are some sandwiches on the table.
    如果你餓了，桌上有三明治。
  6. If you want a quiet place to study, the library is open until nine.
    如果你想找安靜的地方讀書，圖書館開到九點。

⑤ 條件放在後面

  1. You can get to the stadium if you take the number 35 bus.
    你搭三十五號公車就可以到體育場。
  2. My dog barks if someone knocks on the door.
    有人敲門的話，我的狗就會叫。
  3. I always take the stairs if the lift is busy.
    電梯人多的話，我都走樓梯。
  4. Call reception if you need anything.
    你需要什麼的話，就打給櫃台。
  5. My parents worry if I come home late.
    我晚回家的話，我爸媽會擔心。
  6. Students can leave early if they finish the test.
    學生考完的話，可以提早離開。
