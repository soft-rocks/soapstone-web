You should have seen my face. I was so happy.

你真該聽聽那個聲音。

You should have + seen / heard + 名⁠詞

You should have seen、You should have heard、名⁠詞或子⁠句

You should have seen你真該看看。
You should have heard你真該聽聽。
名詞或子句說話者想強調的事。

加⁠上解⁠釋

You should have seen my face. I was so happy.

例句

You should have heard the noise. It was like a bomb.

你真該聽聽那個聲音。就像炸彈一樣。

說完 You should have seen … 以後，常接著說明當時的情況。

see 的過⁠去⁠分⁠詞是 seen

You should have seen my face. I was so happy.

You should have saw his face.

You should have seen his face.

should 和過⁠去⁠分⁠詞中⁠間要⁠有 have

You should have seen my face. I was so happy.

You should seen the view.

You should have seen the view.

疑⁠問⁠詞後⁠面⁠的子⁠句用直⁠述⁠句⁠的順⁠序

You should have seen how big was the fish.

You should have seen how big the fish was.

例句

① You should have seen + 名詞：強調看到的東西

  1. When I opened the door, everyone shouted "Surprise!" You should have seen my face. I was so happy.
    我開門的時候，大家都大喊驚喜！你真該看看我當時的表情。我高興極了。
  2. We went to the top of the tower. You should have seen the view!
    我們上了塔頂。你真該看看那裡的風景！
  3. You should have seen the size of the waves at the beach yesterday.
    你真該看看昨天海灘上的浪有多大。
  4. The kitchen was a disaster after the party. You should have seen the mess.
    派對後廚房一團糟。你真該看看那個亂樣。
  5. You should have seen Dad's face when he opened the bill.
    你真該看看爸爸打開帳單時的表情。
  6. You should have seen the crowd at the final. There were thousands of people.
    你真該看看決賽的人潮。有好幾千人。

② You should have heard + 名詞：強調聽到的聲音

  1. The storm broke a tree in our garden. You should have heard the noise.
    暴風雨把我們花園的一棵樹吹斷了。你真該聽聽那個聲音。
  2. You should have heard the crowd when our team scored.
    我們隊進球的時候，你真該聽聽觀眾的聲音。
  3. You should have heard my grandmother singing at the wedding.
    你真該聽聽我奶奶在婚禮上唱歌。
  4. The baby screamed all night. You should have heard her!
    寶寶哭了一整晚。你真該聽聽她哭的聲音！
  5. You should have heard the jokes he told at dinner.
    你真該聽聽他吃晚餐時說的笑話。
  6. You should have heard the band. They were brilliant.
    你真該聽聽那個樂團。他們太棒了。

③ You should have seen + how / what + 子句

  1. You should have seen how big the fish was. It was nearly a metre long.
    你真該看看那條魚有多大。快一公尺長了。
  2. You should have seen what the children did to the living room.
    你真該看看孩子們把客廳弄成什麼樣子。
  3. You should have seen how fast she ran in the last lap.
    你真該看看她最後一圈跑得多快。
  4. You should have seen how much food there was at the party.
    你真該看看派對上有多少食物。
  5. You should have seen what he was wearing. A pink suit!
    你真該看看他穿什麼。一套粉紅色的西裝！
  6. You should have seen how high the dog jumped.
    你真該看看那隻狗跳得多高。

④ You should have heard + what / how + 子句

  1. You should have heard what the teacher said when she saw the broken window.
    你真該聽聽老師看到破窗戶時說了什麼。
  2. You should have heard how loudly he snored.
    你真該聽聽他打呼有多大聲。
  3. You should have heard what my little brother told the doctor.
    你真該聽聽我弟弟跟醫生說了什麼。
  4. You should have heard how angry the customer was.
    你真該聽聽那個顧客有多生氣。
  5. You should have heard what the waiter said about the soup.
    你真該聽聽服務生怎麼說那道湯。
  6. You should have heard how well she played the violin.
    你真該聽聽她小提琴拉得多好。

⑤ You should have been there / tasted / felt …：其他強調

  1. You should have been there when the bride fell into the pool!
    新娘掉進游泳池的時候，你真該在場！
  2. You should have tasted the cake my aunt made. It was delicious.
    你真該嚐嚐我阿姨做的蛋糕。太好吃了。
  3. You should have felt how cold the water was.
    你真該感受一下水有多冰。
  4. You should have smelt the bread in that little bakery.
    你真該聞聞那家小麵包店的麵包香。
  5. You should have been on the boat when the dolphins came.
    海豚來的時候，你真該在船上。
  6. You should have tasted the street food in Bangkok.
    你真該嚐嚐曼谷的街頭小吃。
  7. You should have been at the airport when my sister came home.
    我姊姊回家的時候，你真該在機場。
